## Special Requirements

These requirements overwrite any preceding requirements in case of conflict, as they are subject specific.

- Focus on theory with minimal explanations but make sure to include non-obvious or non-trivial implications, helpful tips and tricks, and unique example questions with solutions steps that showcase special solution steps.
- Do reference the script by chapter / lemma / other ID but not by page.
- Only summaries the following chapters: [summary range]
- Try to create a compacter content structure to convey a better and full big-picture and do not just use the script structure. For example should multiple operators of the same type but introduced in different chapters just be put together.
- Include **ABSOLUTELY ALL** definitions, theorems, lemmas, conjectures of the summarised chapters **VERBATIM** (with the correct numbering) in separate **MARKDOWN FOOTNOTES** at the end of the summary.
	- Reference them where they are used as source. This can be done multiple times and every footnotes should AT LEAST be referenced once.
	- The summary should be complete and understandable without these verbatim copies. (Meaning some content will be duplicated in the footnotes)
	- You can change the formatting to make them more readable but NEVER the wording or mathematical expressions. Also never add anything else to the footnote.
	- Do not add a separator (`---`) above the footnotes.
- Always use MathJax with $ (Obsidian syntax) for any math expression (prefer inline).
- Use these additional resources and sources:
	- https://discmath.ch/ (Script from Teaching Assistants)
	- https://cs.shivi.io/01-Semesters-(BSc)/Semester-1/Discrete-Maths/ (Summary of Script from a good student)
	- Some presentation slides I might provide from a Teaching Assistent (in PDF or Text format).

Because you need to reference all definitions, theorems, lemmas, conjectures in the summary, list all of them (irrelevant if they are used in the summary) by type and number in step 1.
