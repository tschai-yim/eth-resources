- **Motivation:** A formal, mechanical system for reasoning, free of ambiguity. Uses **formulas**, distinct from "real-world" mathematical statements.
- **Syntax (Building Blocks):**
    - **Propositional Symbols:** Variables for truth values (e.g., $A, B, C$).
    - **Logical Constants:** **$0$** (false) and **$1$** (true).
    - **Logical Operators:** Combine symbols/formulas.
        - $¬$ (Negation / NOT)
        - $∧$ (Conjunction / AND)
        - $∨$ (Disjunction / OR, inclusive)
        - $→$ (Implication)
        - $↔$ (Two-sided Implication / Equivalence)
    - **Formula:** Correctly formed expression of symbols and operators (e.g., $(A \land \neg B) \lor C$).
        - **Precedence:** $¬$ binds strongest (e.g., $¬A ∨ B$ is $(¬A) ∨ B$).

> **Definition 2.3.** *The logical values (constants) "true" and "false" are usually denoted as $1$ and $0$, respectively.*

> **Definition 2.4.**
> *(i) The negation (logical NOT) of a propositional symbol $A$, denoted as $¬A$, is true if and only if $A$ is false.*
> *(ii) The conjunction (logical AND) of two propositional symbol $A$ and $B$, denoted $A \land B$, is true if and only if both $A$ and $B$ are true.*
> *(iii) The disjunction (logical OR) of two propositional symbols $A$ and $B$, denoted $A \lor B$, is true if and only if $A$ or $B$ (or both) are true.*

> **Definition 2.5.** *A correctly formed expression involving the propositional symbols $A, B, C, . . .$ and logical operators is called a formula (of propositional logic).*

- **Semantics (Meaning):**
    - **Truth Tables:** Define operator functions via input-output rules.
    - **Formulas as Functions:** A formula with $n$ symbols induces a function $f: \{0,1\}^n \to \{0,1\}$.
        - **Expressiveness:** Any function $f: \{0,1\}^n \to \{0,1\}$ can be represented by a propositional logic formula.

## **Relationships Between Formulas**

- **Distinction of Symbols is Crucial:**

| Symbol                | Type         | Input        | Output                       | Context                            |
| :-------------------- | :----------- | :----------- | :--------------------------- | :--------------------------------- |
| $F \leftrightarrow G$ | **Operator** | 2 Formulas   | 1 new **Formula**            | Propositional Logic "Toy World"    |
| $F \equiv G$          | **Relation** | 2 Formulas   | 1 **Statement** (true/false) | About Propositional Logic Formulas |
| $S \Leftrightarrow T$ | **Relation** | 2 Statements | 1 new **Statement**          | "Real World" Mathematics           |

- **Logical Equivalence ($≡$):** Two formulas $F, G$ are equivalent if they induce the same function (i.e., have identical truth tables).
    - **Example:** $A \to B \equiv \neg A \lor B$.

> **Definition 2.6.** *Two formulas $F$ and $G$ (in propositional logic) are called equivalent, denoted as $F \equiv G$, if they correspond to the same function, i.e., if the truth values are equal for all truth assignments to the propositional symbols appearing in $F$ or $G$.*

- **Logical Consequence ($\vDash$):** $G$ is a logical consequence of $F$ if $G$ is true whenever $F$ is true.
    - **Example:** $A \land B \vDash A$.
    - **Relationship to $≡$:** $F \equiv G$ if and only if $F \vDash G$ and $G \vDash F$.

> **Definition 2.7.** *A formula $G$ is a logical consequence of a formula $F$, denoted $F \vDash G$, if for all truth assignments to the propositional symbols appearing in $F$ or $G$, the truth value of $G$ is $1$ if the truth value of $F$ is $1$.*

## **Key Logical Equivalences & Properties**

> **Lemma 2.1.**
> *1) $A \land A \equiv A$ and $A \lor A \equiv A$ (idempotence);*
> *2) $A \land B \equiv B \land A$ and $A \lor B \equiv B \lor A$ (commutativity of $∧$ and $∨$);*
> *3) $(A \land B) \land C \equiv A \land (B \land C)$ and $(A \lor B) \lor C \equiv A \lor (B \lor C)$ (associativity);*
> *4) $A \land (A \lor B) \equiv A$ and $A \lor (A \land B) \equiv A$ (absorption);*
> *5) $A \land (B \lor C) \equiv (A \land B) \lor (A \land C)$ (first distributive law);*
> *6) $A \lor (B \land C) \equiv (A \lor B) \land (A \lor C)$ (second distributive law);*
> *7) $¬¬A \equiv A$ (double negation);*
> *8) $¬(A \land B) \equiv ¬A \lor ¬B$ and $¬(A \lor B) \equiv ¬A \land ¬B$ (de Morgan's rules).*

- **Other Useful Equivalences:**
    - **Implication:** $A \to B \equiv \neg A \lor B$
    - **Two-sided Implication:** $A \leftrightarrow B \equiv (A \to B) \land (B \to A)$
    - **Constants:** $A \lor 1 \equiv 1$, $A \land 1 \equiv A$, $A \lor 0 \equiv A$, $A \land 0 \equiv 0$
    - **Lifting:** All rules apply when symbols ($A, B$) are replaced by complex formulas ($F, G$).
- **Formula Properties:**
    - **Tautology (Valid):** Always true. Notation: $\top$, or $\vDash F$.
    - **Satisfiable:** True for at least one truth assignment.
    - **Unsatisfiable (Contradiction):** Always false. Notation: $\bot$.

> **Definition 2.8.** *A formula $F$ (in propositional logic) is called a tautology or valid if it is true for all truth assignments of the involved propositional symbols. One often writes $\vDash F$ to say that $F$ is a tautology.*

> **Definition 2.9.** *A formula $F$ (in propositional logic) is called satisfiable if it is true for at least one truth assignment of the involved propositional symbols, and it is called unsatisfiable otherwise.*

> **Lemma 2.2.** *A formula $F$ is a tautology if and only if $¬F$ is unsatisfiable.*

- **Connection: Tautology & Logical Consequence:**
    - $F \vDash G$ is true if and only if the formula $F \to G$ is a tautology.
    - **Example:** The tautology $(A \land (A \to B)) \to B$ proves $(A \land (A \to B)) \vDash B$.

> **Lemma 2.3.** *For any formulas $F$ and $G$, $F \to G$ is a tautology if and only if $F \vDash G$.*

## **Normal Forms** (not In script)

- **Literal:** Propositional symbol or its negation (e.g., $A$, $¬A$).
- **Disjunctive Normal Form (DNF):** Disjunction of `AND`-clauses of literals.
    - Structure: $(... \land ...) \lor (... \land ...) \lor ...$
    - Example: $(A \land \neg B) \lor (\neg A \land C)$.
    - **From truth table:**
        1. For each row with output **$1$**, form an `AND`-clause true for those inputs.
        2. Combine all such clauses with `OR`.
    - **Simple Example:** A row $(A=1, B=0)$ with output $1$ yields the DNF clause $(A \land \neg B)$.
- **Conjunctive Normal Form (CNF):** Conjunction of `OR`-clauses of literals.
    - Structure: $(... \lor ...) \land (... \lor ...) \land ...$
    - Example: $(A \lor \neg B) \land (\neg A \lor C)$.
    - **From truth table:**
        1. For each row with output **$0$**, form an `OR`-clause false for those inputs.
        2. Combine all such clauses with `AND`.
    - **Simple Example:** A row $(A=1, B=0)$ with output $0$ yields the CNF clause $(\neg A \lor B)$.
