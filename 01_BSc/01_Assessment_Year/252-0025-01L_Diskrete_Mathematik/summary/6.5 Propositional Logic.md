## Foundations of Propositional Logic

### Syntax

- **Atomic Formulas ($A_i$):** Basic symbols representing truth values ($i \in \mathbb{N}$).[^def6.23]
- **Formulas:** Defined inductively.[^def6.23]
    - **Atom:** $A_i$ with $i \in \mathbb{N}$ is a formula.
    - **Step:** If $F, G$ formulas $\implies \neg F, (F \land G), (F \lor G)$ formulas.
    - **Structure:** Tree (leaves = atoms, inner nodes = operators).
    - **Sugar:** $\rightarrow$ (Implication), $\leftrightarrow$ (Equivalence).
- **Literal:** Atomic formula ($A$) or negation ($\neg A$).[^def6.25]

### Semantics

- **Truth Assignment ($\mathcal{A}$):** Function $\mathcal{A}: Z \to \{0, 1\}$ mapping atomic formulas ($Z$) to values.[^def6.24]
- **Interpretation:** Synonymous with truth assignment in propositional logic.
    - **Suitable:** $\mathcal{A}$ assigns values to **all** atomic formulas in $F$.
- **Free Symbols:** **All** atomic formulas in $F$ are free.

## Normal Forms

Any formula transformable to CNF or DNF.[^thm6.4]

### Conjunctive Normal Form (CNF)

- **Structure:** **Conjunction** ($\land$) of **disjunctions** ($\lor$) of literals.[^def6.26]
    - Ex: $(A \lor \neg B) \land (\neg A \lor C)$.
    - "Product of Sums".
- **Usage:** SAT-Solvers, Resolution Calculus.
- **Evaluation:** True iff **every** clause is true.

### Disjunctive Normal Form (DNF)

- **Structure:** **Disjunction** ($\lor$) of **conjunctions** ($\land$) of literals.[^def6.27]
    - Ex: $(A \land B) \lor (\neg A \land C)$.
    - "Sum of Products".
- **Usage:** Satisfiability check trivial (true if **any** conjunction valid).

### Construction Methods

#### 1. Algebraic Transformation (Syntax-based)

Rewrite via equivalences.

- **Step 1:** Eliminate $\rightarrow, \leftrightarrow$ (e.g., $A \rightarrow B \equiv \neg A \lor B$).
- **Step 2:** Push negations inward (De Morgan: $\neg(A \lor B) \equiv \neg A \land \neg B$).
- **Step 3:** Distribute operators.
    - CNF: $A \lor (B \land C) \equiv (A \lor B) \land (A \lor C)$.

#### 2. Truth Table Extraction (Semantics-based)

Algorithmically guaranteed; potentially exponential size.

- **DNF (Sum of Products)**
    - **Source:** Rows with Result **1**.
    - **Rule:** Create **AND**-term. If $A_i=1 \to A_i$; if $A_i=0 \to \neg A_i$.
    - **Combine:** Join terms with **OR**.
- **CNF (Product of Sums)**
    - **Source:** Rows with Result **0**.
    - **Rule:** Create **OR**-clause. If $A_i=0 \to A_i$; if $A_i=1 \to \neg A_i$ (**Invert!**).
    - **Combine:** Join clauses with **AND**.
    - **Example:**
        - Row: $A=1, B=0 \to \text{Result } 0$.
        - Logic: Input $1, 0$ is "forbidden".
        - Clause: $(\neg A \lor B)$. (False only if $A=1, B=0$).

## Resolution Calculus

Syntactic system to prove **unsatisfiability** (Refutation Proof). To prove tautology $F$, refute $\neg F$.

### Components

- **Clause:** **Set** of literals $\equiv$ Disjunction ($L_1 \lor \dots$).[^def6.28]
    - $\emptyset$ (Empty Clause) $\equiv$ **False**.
- **Set of Clauses ($\mathcal{K}(F)$):** Set of clauses $\equiv$ Conjunction ($C_1 \land \dots$).[^def6.29]
    - $\emptyset$ (Empty Set) $\equiv$ **True**.
- **Preprocessing:** Formula $M$ must be converted to CNF first.

### The Resolution Rule

Derive new clause (Resolvent) from parent clauses.[^def6.30]

$$ \frac{K_1, K_2}{K} \quad \text{where } K = (K_1 \setminus \{L\}) \cup (K_2 \setminus \{\neg L\}) $$

- **Variables:**
    - $K_1, K_2$: Parent clauses.
    - $L$: Literal in $K_1$ to eliminate (must have $\neg L \in K_2$).
    - $K$: Resulting resolvent clause.
- **Constraint:** Only **one** pair ($L, \neg L$) resolved per step.
    - **Example:** Resolving $\{A, B\}$ and $\{\neg A, \neg B\}$.
    - *Invalid:* Resolving $A$ and $B$ simultaneously yields $\emptyset$ (False).
    - *Reason:* Input $A=1, B=0$ satisfies original clauses: $(1 \lor 0) \land (0 \lor 1) = 1 \land 1 = 1$. Thus, set is **satisfiable**; deriving $\emptyset$ would be unsound.
    - *Valid:* Resolve only $A$ $\to \{B, \neg B\}$ (Tautology).

### Meta-Properties

- **Soundness:** No false positives. Derived $K$ is logical consequence of $\mathcal{K}$.[^lem6.5]
    - $\mathcal{K} \vdash_{Res} K \implies \mathcal{K} \vDash K$.
- **Completeness (Refutation):** If unsatisfiable, $\emptyset$ can be derived.[^thm6.6]
    - $M$ unsatisfiable $\iff \mathcal{K}(M) \vdash_{Res} \emptyset$.

[^def6.23]: **Definition 6.23.** (Syntax.) An *atomic formula* is a symbol of the form $A_i$ with $i \in \mathbb{N}$. A *formula* is defined as follows, where the second point is a restatement (for convenience) of Definition 6.15:
    - An atomic formula is a formula.
    - If $F$ and $G$ are formulas, then also $\neg F$, $(F \land G)$, and $(F \lor G)$ are formulas.
[^def6.25]: **Definition 6.25.** A *literal* is an atomic formula or the negation of an atomic formula.
[^def6.24]: **Definition 6.24.** (Semantics.) For a set $Z$ of atomic formulas, an interpretation $\mathcal{A}$, called *truth assignment*, is a function $\mathcal{A} : Z \to \{0, 1\}$. A truth assignment $\mathcal{A}$ is suitable for a formula $F$ if $Z$ contains all atomic formulas appearing in $F$ (see Definition 6.7). The semantics (i.e., the truth value $\mathcal{A}(F)$ of a formula $F$ under interpretation $\mathcal{A}$) is defined by $\mathcal{A}(F) = \mathcal{A}(A_i)$ for any atomic formula $F = A_i$, and by Definition 6.16 (restated here for convenience):
    $\mathcal{A}((F \land G)) = 1$ if and only if $\mathcal{A}(F) = 1$ and $\mathcal{A}(G) = 1$.
    $\mathcal{A}((F \lor G)) = 1$ if and only if $\mathcal{A}(F) = 1$ or $\mathcal{A}(G) = 1$.
    $\mathcal{A}(\neg F) = 1$ if and only if $\mathcal{A}(F) = 0$.
[^thm6.4]: **Theorem 6.4.** *Every formula is equivalent to a formula in CNF and also to a formula in DNF.*
[^def6.26]: **Definition 6.26.** A formula $F$ is in *conjunctive normal form (CNF)* if it is a conjunction of disjunctions of literals, i.e., if it is of the form
    $$ F = (L_{11} \lor \dots \lor L_{1m_1}) \land \dots \land (L_{n1} \lor \dots \lor L_{nm_n}) $$
    for some literals $L_{ij}$.
[^def6.27]: **Definition 6.27.** A formula $F$ is in *disjunctive normal form (DNF)* if it is a disjunction of conjunctions of literals, i.e., if it is of the form
    $$ F = (L_{11} \land \dots \land L_{1m_1}) \lor \dots \lor (L_{n1} \land \dots \land L_{nm_n}) $$
    for some literals $L_{ij}$.
[^def6.28]: **Definition 6.28.** A *clause* is a set of literals.
[^def6.29]: **Definition 6.29.** The set of clauses associated to a formula
    $$ F = (L_{11} \lor \dots \lor L_{1m_1}) \land \dots \land (L_{n1} \lor \dots \lor L_{nm_n}) $$
    in CNF, denoted as $\mathcal{K}(F)$, is the set
    $$ \mathcal{K}(F) \overset{\text{def}}{=} \{ \{L_{11}, \dots, L_{1m_1}\}, \dots, \{L_{n1}, \dots, L_{nm_n}\} \}. $$
    The set of clauses associated with a set $M = \{F_1, \dots, F_k\}$ of formulas is the union of their clause sets:
    $$ \mathcal{K}(M) \overset{\text{def}}{=} \bigcup_{i=1}^k \mathcal{K}(F_i). $$
[^def6.30]: **Definition 6.30.** A clause $K$ is a *resolvent* of clauses $K_1$ and $K_2$ if there is a literal $L$ such that $L \in K_1$, $\neg L \in K_2$, and
    $$ K = (K_1 \setminus \{L\}) \cup (K_2 \setminus \{\neg L\}). $$
[^lem6.5]: **Lemma 6.5.** *The resolution calculus is sound, i.e., if $\mathcal{K} \vdash_{\text{Res}} K$ then $\mathcal{K} \vDash K$.*
[^thm6.6]: **Theorem 6.6.** *A set $M$ of formulas is unsatisfiable if and only if $\mathcal{K}(M) \vdash_{\text{Res}} \emptyset$.*
