## Fundamentals of Error-Correcting Codes

- **Goal**: Transmit $k$ symbols as $n$ symbols ($n > k$) to add **redundancy** against noise.
- **Encoding**:
    - **$(n, k)$-encoding function** $E$: Maps message $m \in \mathcal{A}^k$ to **codeword** $c \in \mathcal{A}^n$.[^def5.35]
    - **Error-Correcting Code** $\mathcal{C}$: Set of all valid codewords.[^def5.35]
    - **Alphabet** $\mathcal{A}$: Typically finite field, e.g., $GF(2)$ or $GF(2^8)$.[^def5.36]
- **Hamming Distance**:
    - Count of differing positions between two equal-length strings.[^def5.37]
    - **Minimum Distance ($d_{\min}$)**: Smallest distance between any distinct pair in $\mathcal{C}$.[^def5.38]
    - *Geometric Interpretation*: To ensure unique correction, "spheres" of radius $t$ around codewords must not overlap.

## Error Detection and Correction Capabilities

- **Decoding**: Function $D: \mathcal{A}^n \to \mathcal{A}^k$ mapping received word to most plausible message.[^def5.39]
- **Capabilities**:
    - **Error Detection**: Detects up to $d_{\min} - 1$ errors (received word is invalid).
    - **Error Correction**: Uniquely corrects $\le t$ errors.[^def5.40]
        - *Constraint*: Requires "majority" of distance to remain intact to identify unique neighbor (unlike detection which only requires non-validity).
- **Fundamental Bound**:
    - Corrects $t$ errors **iff** $d_{\min} \ge 2t + 1$.[^thm5.41]
    - Max correctable errors: $t = \lfloor \frac{d_{\min} - 1}{2} \rfloor$.

## Reed-Solomon Codes (Polynomial Evaluation)

- **Concept**: Optimal codes using polynomial properties over **$GF(q)$**.
- **Construction**:
    1. **Message**: Symbols $(a_0, \dots, a_{k-1})$ treated as coefficients of polynomial $a(x)$ (degree $< k$).
    2. **Encoding**: Evaluate $a(x)$ at $n$ distinct points $(\alpha_0, \dots, \alpha_{n-1})$.
    3. **Codeword**: Vector of evaluations $(a(\alpha_0), \dots, a(\alpha_{n-1}))$.[^thm5.42]
- **Constraints**: Field size $|GF(q)| \ge n$.
- **Properties**:
    - **Minimum Distance**: $d_{\min} = n - k + 1$.[^thm5.42]
    - **Singleton Bound**: Theoretical limit stating $d_{\min} \le n - k + 1$ for any code.
    - **MDS (Maximum Distance Separable)**: Codes meeting Singleton bound exactly (like RS); optimal error correction for given redundancy.
    - **Correction Capacity**: $t = \lfloor \frac{n-k}{2} \rfloor$.
- **Decoding Logic**:
    - Find unique polynomial (degree $< k$) passing through $\ge n-t$ received points.
    - Possible since $n-t \ge k+t$ (over-determined system).
- **Applications**: Storage (CD/DVD), Space Comm., QR Codes.

## Secret Sharing (Shamir)

- **Objective**: Split secret $S$ among $n$ participants.
    1. **Recoverability**: Any group $\ge t$ can reconstruct $S$.
    2. **Secrecy**: Any group $< t$ learns **nothing**.
- **Mechanism (Polynomial Interpolation)**:
    - **Setup**:
        - Field size $p > n, S$.
        - Random polynomial $a(x)$ of degree **$t-1$**.
        - Set $a(0) = S$ (secret).
        - Randomize other $t-1$ coefficients.
    - **Distribution**: Participant $i$ gets share $(x_i, a(x_i))$ with $x_i \neq 0$.
- **Reconstruction ($k \ge t$)**:
    - $t$ points uniquely define poly (degree $t-1$) $\to$ compute $a(0)$.[^lem5.32]
- **Security ($k < t$)**:
    - With $t-1$ points, **any** y-intercept ($S'$) fits a unique valid polynomial.
    - Secret is mathematically undetermined (Perfect Secrecy).

## Lagrange Interpolation

- **Theorem**: Polynomial of degree $\le d$ uniquely determined by $d+1$ points.[^lem5.32]
- **Formula**:
    - Basis polynomials $L_j(x)$ where $L_j(x_j)=1$, else $0$.
    - $a(x) = \sum_{j=0}^{d} y_j L_j(x)$ with $L_j(x) = \prod_{i \neq j} \frac{x - x_i}{x_j - x_i}$.

[^def5.35]: **Definition 5.35.** A $(n, k)$-encoding function $E$ for some alphabet $\mathcal{A}$ is an injective function that maps a list $(a_0, \dots, a_{k-1}) \in \mathcal{A}^k$ of $k$ (information) symbols to a list $(c_0, \dots, c_{n-1}) \in \mathcal{A}^n$ of $n > k$ (encoded) symbols in $\mathcal{A}$, called *codeword*: $E : \mathcal{A}^k \to \mathcal{A}^n : (a_0, \dots, a_{k-1}) \mapsto E((a_0, \dots, a_{k-1})) = (c_0, \dots, c_{n-1})$.
[^def5.36]: **Definition 5.36.** An $(n, k)$-error-correcting code over the alphabet $\mathcal{A}$ with $|\mathcal{A}| = q$ is a subset of $\mathcal{A}^n$ of cardinality $q^k$.
[^def5.37]: **Definition 5.37.** The *Hamming distance* between two strings of equal length over a finite alphabet $\mathcal{A}$ is the number of positions at which the two strings differ.
[^def5.38]: **Definition 5.38.** The *minimum distance* of an error-correcting code $\mathcal{C}$, denoted $d_{\min}(\mathcal{C})$, is the minimum of the *Hamming distance* between any two codewords.
[^def5.39]: **Definition 5.39.** A decoding function $D$ for an $(n, k)$-encoding function is a function $D : \mathcal{A}^n \to \mathcal{A}^k$.
[^def5.40]: **Definition 5.40.** A decoding function $D$ is $t$-error correcting for encoding function $E$ if for any $(a_0, \dots, a_{k-1})$ $D((r_0, \dots, r_{n-1})) = (a_0, \dots, a_{k-1})$ for any $(r_0, \dots, r_{n-1})$ with Hamming distance at most $t$ from $E((a_0, \dots, a_{k-1}))$. A code $\mathcal{C}$ is $t$-error correcting if there exists $E$ and $D$ with $\mathcal{C} = Im(E)$ where $D$ is $t$-error correcting.
[^thm5.41]: **Theorem 5.41.** A code $\mathcal{C}$ with minimum distance $d$ is $t$-error correcting if and only if $d \ge 2t + 1$.
[^thm5.42]: **Theorem 5.42.** Let $\mathcal{A} = \text{GF}(q)$ and let $\alpha_0, \dots, \alpha_{n-1}$ be arbitrary distinct elements of $\text{GF}(q)$. Consider the encoding function $E((a_0, \dots, a_{k-1})) = (a(\alpha_0), \dots, a(\alpha_{n-1}))$, where $a(x)$ is the polynomial $a(x) = a_{k-1}x^{k-1} + \dots + a_1x + a_0$. This code has minimum distance $n - k + 1$.
[^lem5.32]: **Lemma 5.32.** A polynomial $a(x) \in F[x]$ of degree at most $d$ is uniquely determined by any $d+1$ values of $a(x)$, i.e., by $a(\alpha_1), \dots, a(\alpha_{d+1})$ for any distinct $\alpha_1, \dots, \alpha_{d+1} \in F$.
