## Foundational Concepts of Set Theory

- **Problem: Inconsistent Naive Set Theory**
    - The naive view of a set as any collection of objects leads to contradictions.
    - **Russell's Paradox**: The set $R = \{A \mid A \text{ is a set and } A \notin A\}$ creates a logical contradiction when checking if $R \in R$.
    - **Implication**: One cannot form a set from any arbitrary property. The "universe of all sets" is not a set itself.
- **Solution: Axiomatic Set Theory**
    - Rigorously regulates the existence and construction of sets through **axioms**.
    - **Key Principle**: New sets can only be constructed from pre-existing sets.

## Fundamental Definitions and Relations

- **Set and Element (`∈`)**:
    - The universe consists only of **sets**; elements of sets are also sets.
    - The fundamental relation is the **elementhood predicate**: $x \in A$ ("x is an element of A").
- **Equality (`=`)**:
    - **Axiom of Extensionality**: Two sets are equal if and only if they have the same elements.[^def3.2]
        - Order and duplicates do not matter, e.g., $\{1, 2, 1\} = \{2, 1\}$.
    - **Proof Method**: Two sets are equal if and only if each is a subset of the other: $A = B \iff (A \subseteq B \land B \subseteq A)$.[^lem3.2]
- **Subsets (`⊆`)**:
    - A set $A$ is a **subset** of $B$ ($A \subseteq B$) if every element of $A$ is also an element of $B$.[^def3.3]
    - **Transitivity**: If $A \subseteq B$ and $B \subseteq C$, then $A \subseteq C$.[^lem3.3]
    - **Crucial Distinction (`∈` vs. `⊆`)**:
        - **Example**: For $C = \{\emptyset, \{\emptyset\}\}$:
            - $\emptyset \in C$ is **true**.
            - $\{\emptyset\} \in C$ is **true**.
            - $\{\emptyset\} \subseteq C$ is **true** (its only element, $\emptyset$, is in $C$).
            - $C \in D$ is **true** for $D = \{\emptyset, \{\emptyset, \{\emptyset\}\}\}$ (the entire set $C$ is an element of $D$).
- **The Empty Set (`∅`)**:
    - The unique set containing no elements, written $\emptyset$ or {}.[^def3.6]
    - Its existence is guaranteed by an axiom.
    - **Uniqueness**: There is only one empty set.[^lem3.5]
    - **Property**: It is a subset of every set: $\forall A (\emptyset \subseteq A)$.[^lem3.6]

## Constructing and Operating on Sets

- **Basic Constructions**:
    - Axioms guarantee the existence of **singleton sets** $\{a\}$ and finite sets $\{a, b, c\}$ from existing sets.
    - It can be proven that if $\{a\} = \{b\}$, then $a=b$.[^lem3.1]
- **Set Operations**:
    - **Union ($A \cup B$)**: Set of elements in $A$, or in $B$, or in both.[^def3.4]
    - **Intersection ($A \cap B$)**: Set of elements in both $A$ and $B$.[^def3.4]
    - **Set Difference ($B \setminus A$)**: Set of elements in $B$ but not in $A$.[^def3.5]
    - **Laws of Set Algebra**: Follow logical laws like commutativity, associativity, and distributivity.[^thm3.4]
        - **Example (Distributivity)**: $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.
- **Advanced Constructions**:
    - **Power Set ($P(A)$)**: The set of **all subsets** of a set $A$.[^def3.7]
        - **Cardinality**: If $|A| = k$, then $|P(A)| = 2^k$.[^def3.1]
        - **Example**: $P(\{a, b\}) = \{\emptyset, \{a\}, \{b\}, \{a, b\}\}$.
    - **Cartesian Product ($A \times B$)**: The set of all **ordered pairs** $(a, b)$ where $a \in A$ and $b \in B$.[^def3.8]
        - **Cardinality**: $|A \times B| = |A| \cdot |B|$.
        - **Set-theoretic Definition of Pairs**: Ordered pairs can be defined using only sets, e.g., $(a, b) \stackrel{\text{def}}{=} \{\{a\}, \{a, b\}\}$. This ensures $(a, b) = (c, d) \iff a=c \land b=d$.

## Set-Theoretic Construction of Numbers

- **Natural Numbers as Sets (von Neumann Ordinals)**: Natural numbers can be constructed from the empty set.
    - $\mathbf{0} \stackrel{\text{def}}{=} \emptyset$
    - $\mathbf{1} \stackrel{\text{def}}{=} \{\emptyset\} = \{\mathbf{0}\}$
    - $\mathbf{2} \stackrel{\text{def}}{=} \{\emptyset, \{\emptyset\}\} = \{\mathbf{0}, \mathbf{1}\}$
    - $\mathbf{3} \stackrel{\text{def}}{=} \{\emptyset, \{\emptyset\}, \{\emptyset, \{\emptyset\}\}\} = \{\mathbf{0}, \mathbf{1}, \mathbf{2}\}$
- **Successor Function**: The general rule for construction.
    - $s(\mathbf{n}) \stackrel{\text{def}}{=} \mathbf{n} \cup \{\mathbf{n}\}$.
    - This construction ensures that the cardinality of the set representing a number is the number itself: $|\mathbf{n}| = n$.

[^lem3.5]: **Lemma 3.5.** There is only one empty set (which is often denoted as $\emptyset$ or {}).
[^lem3.6]: **Lemma 3.6.** The empty set is a subset of every set, i.e., $\forall A (\emptyset \subseteq A)$.
[^lem3.1]: **Lemma 3.1.** For any (sets) $a$ and $b$, $\{a\} = \{b\} \implies a = b$.
[^def3.4]: **Definition 3.4.** The **union** of two sets $A$ and $B$ is defined as $A \cup B \stackrel{\text{def}}{=} \{x \mid x \in A \lor x \in B\}$, and their **intersection** is defined as $A \cap B \stackrel{\text{def}}{=} \{x \mid x \in A \land x \in B\}$.
[^def3.5]: **Definition 3.5.** The **difference** of sets $B$ and $A$, denoted $B \setminus A$ is the set of elements of $B$ without those that are elements of $A$: $B \setminus A \stackrel{\text{def}}{=} \{x \in B \mid x \notin A\}$.
[^thm3.4]: **Theorem 3.4.** For any sets $A$, $B$, and $C$, the following laws hold:
    - **Idempotence:** $A \cap A = A$; $A \cup A = A$;
    - **Commutativity:** $A \cap B = B \cap A$; $A \cup B = B \cup A$;
    - **Associativity:** $A \cap (B \cap C) = (A \cap B) \cap C$; $A \cup (B \cup C) = (A \cup B) \cup C$;
    - **Absorption:** $A \cap (A \cup B) = A$; $A \cup (A \cap B) = A$;
    - **Distributivity:** $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$; $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$;
    - **Consistency:** $A \subseteq B \iff A \cap B = A \iff A \cup B = B$.
[^def3.7]: **Definition 3.7.** The **power set** of a set $A$, denoted $P(A)$, is the set of all subsets of $A$: $P(A) \stackrel{\text{def}}{=} \{S \mid S \subseteq A\}$.
[^def3.1]: **Definition 3.1. (Informal.)** The number of elements of a finite set $A$ is called its **cardinality** and is denoted $|A|$.
[^def3.8]: **Definition 3.8.** The **Cartesian product** $A \times B$ of two sets $A$ and $B$ is the set of all ordered pairs with the first component from $A$ and the second component from $B$: $A \times B = \{(a, b) \mid a \in A \land b \in B\}$.
