## Proof Systems (The Meta-Framework)

- **Goal**: Framework for expressing statements and mechanical proof verification.[^def6.1]
- **Components $\Pi = (S, P, \tau, \phi)$**:[^def6.1]
    - $S$: Set of **statements** (syntactic objects, e.g., strings).
    - $P$: Set of **proofs** (syntactic objects, e.g., bit-strings).
    - $\tau$: **Truth function** ($S \to \{0, 1\}$). Defines **semantics**.
    - $\phi$: **Verification function** ($S \times P \to \{0, 1\}$). Decides if $p$ is valid proof for $s$.
- **Fundamental Requirements**:
    - **Soundness**: No false statement has a proof ($\phi(s, p) = 1 \implies \tau(s) = 1$).[^def6.2]
    - **Completeness**: Every true statement has a proof ($\tau(s) = 1 \implies \exists p, \phi(s, p) = 1$).[^def6.3]
- **Efficiency**:
    - **Verification ($\phi$)**: Must be **efficiently computable** (polynomial time).
    - **Proof Generation**: Generally **hard** (requires insight, often NP-hard).
    - **Asymmetry**: Easy to prove existence (witness); hard to prove non-existence (e.g., no Hamiltonian Cycle).0
- **Examples**:
    - **Hamiltonian Cycle**: $S$ = Graphs; $P$ = Node sequence; $\phi$ checks adjacency. Sound & Complete.
    - **Primality**:
        - $S$ = Integers. Since AKS, verification is efficient without a "certificate" ($P$ can be empty).
        - **AKS Algorithm**: Deterministic polynomial-time primality test.
    - **Graph 3-Coloring**: $P$ = Color assignment; $\phi$ checks neighbor colors.

## General Logic Concepts: Syntax & Semantics

### Syntax (Form)

- **Formula**: String over alphabet $\Lambda$ defined by syntax rules.[^def6.4]
    - Purely syntactic; no truth value without interpretation.
- **Variables**: Symbols in $\Lambda$ serving as placeholders.

### Semantics (Meaning)

- **Free Variables**: Indices/symbols in formula $F$ requiring external value assignment ($free(F)$).[^def6.5]
    - *Propositional Logic*: Atomic propositions are "free".
    - *Predicate Logic*: Quantifiers bind variables.
- **Interpretation $\mathcal{A}$**: Consists of:[^def6.6]
    - Set of symbols $\mathcal{Z} \subseteq \Lambda$.
    - **Domain**: Set of possible values for each symbol.
    - Mapping assigning values from domain to symbols.
- **Suitable Interpretation**: Assigns values to **all** free symbols in $F$.[^def6.7]
- **Truth Value $\sigma(F, \mathcal{A})$**: Maps $F$ to $\{0, 1\}$ under suitable $\mathcal{A}$ (denoted $\mathcal{A}(F)$).[^def6.8]

### Models

- **Model**: Interpretation $\mathcal{A}$ where $\mathcal{A}(F) = 1$ (denoted $\mathcal{A} \vDash F$).[^def6.9]
    - **Set of formulas $M$**: $\mathcal{A} \vDash M \iff \forall F \in M, \mathcal{A} \vDash F$.
    - **Not a model**: $\mathcal{A} \not\vDash M$.

## Logical Properties and Relationships

- **Satisfiability**:
    - **Satisfiable**: At least one model exists for $F$ (or $M$).[^def6.10]
    - **Unsatisfiable ($\perp$)**: No model exists.[^def6.10]
- **Validity (Tautology $\top$)**:
    - True for **every** suitable interpretation ($\vDash F$).[^def6.11] [^def6.14]
    - **Relation**: $F$ is tautology $\iff \neg F$ is unsatisfiable.[^lem6.2]
- **Logical Consequence ($\vDash$)**:
    - $F \vDash G$: Every model for $F$ is also a model for $G$.[^def6.12]
    - **Key Equivalence**: The following are equivalent:[^lem6.3]
        1. $\{F_1, \dots, F_k\} \vDash G$
        2. $(F_1 \land \dots \land F_k) \to G$ is a tautology.
        3. $\{F_1, \dots, F_k, \neg G\}$ is unsatisfiable.
- **Logical Equivalence ($\equiv$)**:
    - Same truth value in every interpretation.[^def6.13]
    - Definition: $F \equiv G \iff (F \vDash G \land G \vDash F)$.[^def6.13]

## Logical Operators and Algebra

- **Standard Operators**: $\neg F$, $(F \land G)$, $(F \lor G)$.[^def6.15]
    - **Semantics**: Standard boolean logic (AND, OR, NOT).[^def6.16]
- **Syntactic Sugar**:
    - $F \to G \equiv \neg F \lor G$.
    - $F \leftrightarrow G \equiv (F \land G) \lor (\neg F \land \neg G)$.
- **Fundamental Equivalences**:[^lem6.1]
    - **Idempotence**: $F \land F \equiv F$; $F \lor F \equiv F$.
    - **Commutativity**: Order irrelevant for $\land, \lor$.
    - **Associativity**: Grouping irrelevant for same operators.
    - **Absorption**: $F \land (F \lor G) \equiv F$.
    - **Distributive**: $F \land (G \lor H) \equiv (F \land G) \lor (F \land H)$.
    - **Double Negation**: $\neg \neg F \equiv F$.
    - **De Morgan**: $\neg (F \land G) \equiv \neg F \lor \neg G$.
    - **Constants**: $F \lor \top \equiv \top$; $F \land \bot \equiv \bot$; $F \lor \neg F \equiv \top$.

## Logical Calculi (Syntactic Derivation)

### Definitions & Mechanism

- **Goal**: Purely syntactic, mechanizable verification.
- **Calculus $K$**: Finite set of derivation rules $\{R_1, \dots, R_m\}$.[^def6.19]
- **Derivation Rule**: Relation to derive formula $G$ from premises $\{F_1, \dots, F_k\}$ (Notation: $\vdash_R$).[^def6.17]
    - **Application**: Add derived $G$ to set of known formulas.[^def6.18]
- **Derivation**: Sequence of rule applications starting from $M$ leading to $G$ ($M \vdash_K G$).[^def6.20]
    - **Hilbert-Style**: Manipulates formulas directly.

### Meta-Properties (Syntax vs. Semantics)

- **Correctness (Rule)**: Rule implies logical consequence ($M \vdash_R F \implies M \vDash F$).[^def6.21]
- **Soundness (Calculus)**: Everything derivable is a logical consequence.[^def6.22]
    - $M \vdash_K F \implies M \vDash F$ ("No lies derived").
- **Completeness (Calculus)**: Every logical consequence is derivable.[^def6.22]
    - $M \vDash F \implies M \vdash_K F$ ("All truths derived").

### Examples & Theorems

- **Common Rules**:
    - **Modus Ponens**: $\{F, F \to G\} \vdash G$.
    - **Case Distinction**: $\{F \lor G, F \to H, G \to H\} \vdash H$.
    - **Proof by Contradiction**: $\{F \lor G, \neg G\} \vdash F$.
- **Deduction Theorem**:
    - $F \vdash_K G \implies \vDash (F \to G)$.
    - Proves implication by assuming premise and deriving conclusion.

[^def6.1]: **Definition 6.1.** A *proof system* is a quadruple $\Pi = (\mathcal{S}, \mathcal{P}, \tau, \phi)$, as above.
[^def6.2]: **Definition 6.2.** A proof system $\Pi = (\mathcal{S}, \mathcal{P}, \tau, \phi)$ is *sound* if no false statement has a proof, i.e., if for all $s \in \mathcal{S}$ for which there exists $p \in \mathcal{P}$ with $\phi(s, p) = 1$, we have $\tau(s) = 1$.
[^def6.3]: **Definition 6.3.** A proof system $\Pi = (\mathcal{S}, \mathcal{P}, \tau, \phi)$ is *complete* if every true statement has a proof, i.e., if for all $s \in \mathcal{S}$ with $\tau(s) = 1$, there exists $p \in \mathcal{P}$ with $\phi(s, p) = 1$.
[^def6.4]: **Definition 6.4.** The *syntax* of a logic defines an alphabet $\Lambda$ (of allowed symbols) and specifies which strings in $\Lambda^*$ are *formulas* (i.e., are syntactically correct).
[^def6.5]: **Definition 6.5.** The *semantics* of a logic defines (among other things, see below) a function *free* which assigns to each formula $F = (f_1, f_2, \dots, f_k) \in \Lambda^*$ a subset $free(F) \subseteq \{1, \dots, k\}$ of the indices. If $i \in free(F)$, then the symbol $f_i$ is said to *occur free in* $F$.
[^def6.6]: **Definition 6.6.** An *interpretation* consists of a set $\mathcal{Z} \subseteq \Lambda$ of symbols of $\Lambda$, a domain (a set of possible values) for each symbol in $\mathcal{Z}$, and a function that assigns to each symbol in $\mathcal{Z}$ a value in its associated domain.
[^def6.7]: **Definition 6.7.** An interpretation is *suitable* for a formula $F$ if it assigns a value to all symbols $\beta \in \Lambda$ occurring free in $F$.
[^def6.8]: **Definition 6.8.** The *semantics* of a logic also defines a function $\sigma$ assigning to each formula $F$, and each interpretation $\mathcal{A}$ suitable for $F$, a truth value $\sigma(F, \mathcal{A})$ in $\{0, 1\}$.
[^def6.9]: **Definition 6.9.** A (suitable) interpretation $\mathcal{A}$ for which a formula $F$ is true, (i.e., $\mathcal{A}(F) = 1$) is called a *model* for $F$, and one also writes
$$ \mathcal{A} \vDash F. $$
More generally, for a set $M$ of formulas, a (suitable) interpretation for which all formulas in $M$ are true is called a *model for* $M$, denoted as
$$ \mathcal{A} \vDash M. $$
If $\mathcal{A}$ is not a model for $M$ one writes $\mathcal{A} \not\vDash M$.
[^def6.10]: **Definition 6.10.** A formula $F$ (or set $M$ of formulas) is called *satisfiable* if there exists a model for $F$ (or $M$), and *unsatisfiable* otherwise. The symbol $\perp$ is used for an unsatisfiable formula.
[^def6.11]: **Definition 6.11.** A formula $F$ is called a *tautology* or *valid* if it is true for every suitable interpretation. The symbol $\top$ is used for a tautology.
[^def6.14]: **Definition 6.14.** If $F$ is a tautology, one also writes $\vDash F$.
[^lem6.2]: **Lemma 6.2.** *A formula $F$ is a tautology if and only if $\neg F$ is unsatisfiable.*
[^def6.12]: **Definition 6.12.** A formula $G$ is a *logical consequence* of a formula $F$ (or a set $M$ of formulas), denoted
$$ F \vDash G \quad (\text{or} \quad M \vDash G), $$
if every interpretation suitable for both $F$ (or $M$) and $G$, which is a model for $F$ (for $M$), is also a model for $G$.
[^lem6.3]: **Lemma 6.3.** *The following three statements are equivalent:*
*1. $\{F_1, F_2, \dots, F_k\} \vDash G$,*
*2. $(F_1 \land F_2 \land \dots \land F_k) \to G$ is a tautology,*
*3. $\{F_1, F_2, \dots, F_k, \neg G\}$ is unsatisfiable.*
[^def6.13]: **Definition 6.13.** Two formulas $F$ and $G$ are *equivalent*, denoted $F \equiv G$, if every interpretation suitable for both $F$ and $G$ yields the same truth value for $F$ and $G$, i.e., if each one is a logical consequence of the other:
$$ F \equiv G \overset{\text{def}}{\Longleftrightarrow} F \vDash G \text{ and } G \vDash F. $$
[^def6.15]: **Definition 6.15.** If $F$ and $G$ are formulas, then also $\neg F$, $(F \land G)$, and $(F \lor G)$ are formulas.
[^def6.16]: **Definition 6.16.**
$\mathcal{A}((F \land G)) = 1 \text{ if and only if } \mathcal{A}(F) = 1 \text{ and } \mathcal{A}(G) = 1.$
$\mathcal{A}((F \lor G)) = 1 \text{ if and only if } \mathcal{A}(F) = 1 \text{ or } \mathcal{A}(G) = 1.$
$\mathcal{A}(\neg F) = 1 \text{ if and only if } \mathcal{A}(F) = 0.$
[^lem6.1]: **Lemma 6.1.** *For any formulas $F, G$, and $H$ we have*
*1) $F \land F \equiv F$ and $F \lor F \equiv F$ (idempotence);*
*2) $F \land G \equiv G \land F$ and $F \lor G \equiv G \lor F$ (commutativity);*
*3) $(F \land G) \land H \equiv F \land (G \land H)$ and $(F \lor G) \lor H \equiv F \lor (G \lor H)$ (associativity);*
*4) $F \land (F \lor G) \equiv F$ and $F \lor (F \land G) \equiv F$ (absorption);*
*5) $F \land (G \lor H) \equiv (F \land G) \lor (F \land H)$ (distributive law);*
*6) $F \lor (G \land H) \equiv (F \lor G) \land (F \lor H)$ (distributive law);*
*7) $\neg\neg F \equiv F$ (double negation);*
*8) $\neg(F \land G) \equiv \neg F \lor \neg G$ and $\neg(F \lor G) \equiv \neg F \land \neg G$ (de Morgan's rules);*
*9) $F \lor \top \equiv \top$ and $F \land \top \equiv F$ (tautology rules);*
*10) $F \lor \perp \equiv F$ and $F \land \perp \equiv \perp$ (unsatisfiability rules).*
*11) $F \lor \neg F \equiv \top$ and $F \land \neg F \equiv \perp$.*
[^def6.19]: **Definition 6.19.** A (logical) *calculus* $K$ is a finite set of derivation rules: $K = \{R_1, \dots, R_m\}$.
[^def6.17]: **Definition 6.17.** A *derivation rule* or *inference rule* is a rule for deriving a formula from a set of formulas (called the precondition or premises). We write
$$ \{F_1, \dots, F_k\} \vdash_R G $$
if $G$ can be derived from the set $\{F_1, \dots, F_k\}$ by rule $R$. Formally, a derivation rule $R$ is a relation from the power set of the set of formulas to the set of formulas, and the symbol $\vdash_R$ can be understood as the relation symbol.
[^def6.18]: **Definition 6.18.** The *application of a derivation rule* $R$ to a set $M$ of formulas means
    1. Select a subset $N$ of $M$ such that $N \vdash_R G$ for some formula $G$.
    2. Add $G$ to the set $M$ (i.e., replace $M$ by $M \cup \{G\}$).
[^def6.20]: **Definition 6.20.** A *derivation* of a formula $G$ from a set $M$ of formulas in a calculus $K$ is a finite sequence (of some length $n$) of applications of rules in $K$ (see Def. 6.18), leading to $G$. More precisely, we have
    - $M_0 := M$,
    - $M_i := M_{i-1} \cup \{G_i\}$ for $1 \le i \le n$, where $N \vdash_{R_j} G_i$ for some $N \subseteq M_{i-1}$ and for some $R_j \in K$, and where
    - $G_n = G$.
We write
$$ M \vdash_K G $$
if there is a derivation of $G$ from $M$ in the calculus $K$.
[^def6.21]: **Definition 6.21.** A derivation rule $R$ is *correct* if for every set $M$ of formulas and every formula $F$, $M \vdash_R F$ implies $M \vDash F$:
$$ M \vdash_R F \implies M \vDash F. $$
[^def6.22]: **Definition 6.22.** A calculus $K$ is *sound* or *correct* if for every set $M$ of formulas and every formula $F$, if $F$ can be derived from $M$ then $F$ is also a logical consequence of $M$:
$$ M \vdash_K F \implies M \vDash F, $$
and $K$ is *complete* if for every $M$ and $F$, if $F$ is a logical consequence of $M$, then $F$ can also be derived from $M$:
$$ M \vDash F \implies M \vdash_K F. $$
