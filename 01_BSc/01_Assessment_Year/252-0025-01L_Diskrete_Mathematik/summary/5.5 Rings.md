## Fundamental Ring Structure

- **Definition of a Ring**: Algebra $\langle R; +, -, 0, \cdot, 1 \rangle$ satisfying:[^def5.18]
    - **Additive Structure**: $\langle R; +, -, 0 \rangle$ is **commutative (abelian) group**.
        - Associativity, identity ($0$), inverse ($-a$), commutativity.
    - **Multiplicative Structure**: $\langle R; \cdot, 1 \rangle$ is **monoid**.
        - Associativity, identity ($1$).
        - **Note**: Inverses/commutativity **not** required.
    - **Interaction**: **Distributive laws** link operations ($a(b+c) = ab+ac$).
- **Ring Types**:
    - **Commutative**: Multiplication is commutative ($ab=ba$).[^def5.18]
        - Ex: $\mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{C}, \mathbb{Z}_m$.
    - **Non-Commutative**: Order matters (e.g., Matrix rings).
    - **Non-Trivial**: $|R| > 1 \implies 1 \neq 0$.[^lem5.17]
- **Arithmetic Properties**:[^lem5.17]
    - **Zero**: $0a = a0 = 0$ (annihilator).
    - **Signs**: $(-a)b = -(ab) = a(-b)$ and $(-a)(-b) = ab$.
- **Characteristic ($\text{char}(R)$)**:[^def5.19]
    - **Definition**: Additive order of multiplicative identity $1$.
    - Smallest $k > 0$ where $\underbrace{1+\dots+1}_{k} = 0$.
    - **Infinite Order**: If sum never reaches $0$, $\text{char}(R) = 0$.
        - **Rationale**: Corresponds to the kernel of the homomorphism $\mathbb{Z} \to R$. If $1$ has infinite order, the kernel is $\{0\}$ (generated by $0$).
    - **Examples**: $\text{char}(\mathbb{Z}) = 0$; $\text{char}(\mathbb{Z}_m) = m$.

## Units and Multiplicative Structure

- **Units ($R^*$)**: Elements $u \in R$ with multiplicative inverse ($uv=1$).[^def5.20]
- **Group Structure**: $R^*$ forms a **multiplicative group**.[^lem5.18]
    - Closed under multiplication, contains $1$, contains inverses.
- **Examples**:
    - $\mathbb{Z}^* = \{1, -1\}$.
    - $\mathbb{R}^* = \mathbb{R} \setminus \{0\}$.
    - $\mathbb{Z}_m^* = \{a \in \mathbb{Z}_m \mid \gcd(a, m) = 1\}$.

## Divisibility and Structure

- **Divisibility ($a \mid b$)**: Commutative ring relation.[^def5.21_mod]
    - **Definition**: $a \neq 0$ and exists $c \in R$ such that $b = ac$.
    - **Correction**: $a \neq 0$ fixes a script inconsistency mentioned in the [2025-11-24](https://video.ethz.ch/lectures/d-infk/2025/autumn/252-0025-01L/v/IBzqxzZEqRH?t=20s) lecture.
    - **Universal**: $1, -1$ divide everything.
    - **Zero**: Non-zero elements divide $0$ ($a \cdot 0 = 0$).
- **Properties**:[^lem5.19]
    - **Transitivity**: $a \mid b \land b \mid c \implies a \mid c$.
    - **Linearity**: $a \mid b \implies a \mid bc$.
    - **Additivity**: $a \mid b \land a \mid c \implies a \mid (b+c)$.
- **Greatest Common Divisor (GCD)**:[^def5.22]
    - $d = \gcd(a,b)$ if:
        1. **Common**: $d \mid a \land d \mid b$.
        2. **Greatest**: $\forall c (c \mid a \land c \mid b \implies c \mid d)$.

## Zero Divisors and Integral Domains

- **Zero Divisors**: Non-zero $a$ where $\exists b \neq 0 : ab = 0$.[^def5.23]
    - **Consequence**: Breaks cancellation ($2 \cdot 3 = 0$ in $\mathbb{Z}_6$).
    - **Constraint**: Units are never zero divisors.
- **Integral Domain**: "Well-behaved" ring.[^def5.24]
    - **Definition**: **Commutative**, **Non-trivial** ($1 \neq 0$), **No zero divisors**.
    - **Logic**: $ab=0 \implies a=0 \lor b=0$.
- **Cancellation Law**: Valid in Integral Domains.[^lem5.20]
    - $ab = ac \land a \neq 0 \implies b = c$.
    - **Uniqueness**: Quotient $b/a$ is unique if defined.
- **Examples**:
    - **Yes**: $\mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{Z}_p$ ($p$ prime).
    - **No**: $\mathbb{Z}_m$ ($m$ composite), Matrices.

[^def5.18]: **Definition 5.18.** A ring $\langle R; +, -, 0, \cdot, 1 \rangle$ is an algebra for which <br> (i) $\langle R; +, -, 0 \rangle$ is a commutative group. <br> (ii) $\langle R; \cdot, 1 \rangle$ is a monoid. <br> (iii) $a(b + c) = (ab) + (ac)$ and $(b + c)a = (ba) + (ca)$ for all $a, b, c \in R$ (left and right distributive laws). <br> A ring is called *commutative* if multiplication is commutative ($ab = ba$).
[^lem5.17]: **Lemma 5.17.** For any ring $\langle R; +, -, 0, \cdot, 1 \rangle$, and for all $a, b \in R$, <br> (i) $0a = a0 = 0$. <br> (ii) $(-a)b = -(ab)$. <br> (iii) $(-a)(-b) = ab$. <br> (iv) If $R$ is non-trivial (i.e., if it has more than one element), then $1 \neq 0$.
[^def5.19]: **Definition 5.19.** The *characteristic* of a ring is the order of 1 in the additive group if it is finite, and otherwise the characteristic is defined to be 0 (not infinite).
[^def5.20]: **Definition 5.20.** An element $u$ of a ring $R$ is called a *unit* if $u$ is invertible, i.e., $uv = vu = 1$ for some $v \in R$. (We write $v = u^{-1}$.) The set of units of $R$ is denoted by $R^*$.
[^lem5.18]: **Lemma 5.18.** For a ring $R$, $R^*$ is a group (the multiplicative group of units of $R$).
[^def5.21_mod]: **Definition 5.21 (Modified).** For $a, b \in R$ we say that $a$ *divides* $b$, denoted $a \mid b$, if there exists $c \in R$ such that $b = ac$ and $a \neq 0$. In this case, $a$ is called a *divisor* of $b$ and $b$ is called a *multiple* of $a$. (Note: Original script omits the nonzero condition, leading to ambiguity with Lemma 5.20).
[^lem5.19]: **Lemma 5.19.** In any commutative ring, <br> (i) If $a \mid b$ and $b \mid c$, then $a \mid c$, i.e., the relation $\mid$ is transitive. <br> (ii) If $a \mid b$, then $a \mid bc$ for all $c$. <br> (iii) If $a \mid b$ and $a \mid c$, then $a \mid (b + c)$.
[^def5.22]: **Definition 5.22.** For ring elements $a$ and $b$ (not both 0), a ring element $d$ is called a *greatest common divisor* of $a$ and $b$ if $d$ divides both $a$ and $b$ and if every common divisor of $a$ and $b$ divides $d$, i.e., if <br> $d \mid a \land d \mid b \land \forall c ((c \mid a \land c \mid b) \to c \mid d)$.
[^def5.23]: **Definition 5.23.** An element $a \neq 0$ of a commutative ring $R$ is called a *zerodivisor* if $ab = 0$ for some $b \neq 0$ in $R$.
[^def5.24]: **Definition 5.24.** An *integral domain* $D$ is a (nontrivial) commutative ring without zerodivisors: For all $a, b \in D$ we have $ab = 0 \implies a = 0 \lor b = 0$.
[^lem5.20]: **Lemma 5.20.** In an integral domain, if $a \mid b$, then $c$ with $b = ac$ is unique (and is denoted by $c = \frac{b}{a}$ or $c = b/a$ and called quotient).
