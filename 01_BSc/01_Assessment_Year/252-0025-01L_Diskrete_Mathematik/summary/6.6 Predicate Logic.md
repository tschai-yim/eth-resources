## Syntax

- **Components** (Alphabet):[^def6.31]
    - **Variable symbols**: $x_i$ (usually $x, y, z$). Placeholders for objects.
    - **Function symbols** ($f_i^{(k)}$): Map $k$ objects to 1 object.
        - **Constants**: Function symbols with $k=0$ (e.g., $a, b$).
    - **Predicate symbols** ($P_i^{(k)}$): Map $k$ objects to **truth value** $\{0, 1\}$.
- **Terms vs. Formulas**:
    - **Term ($t$)**: Evaluates to an **element** of the universe (e.g., $f(x)$).[^def6.31]
    - **Formula ($F$)**: Evaluates to a **truth value** (e.g., $P(x)$).[^def6.31]
        - Built recursively: Atomic formulas $P(t_1, \dots)$, operators ($\neg, \land, \lor$), and quantifiers.
- **Quantifiers**:
    - **Universal ($\forall x F$)**: "For all $x$ in the universe, $F$ is true."
    - **Existential ($\exists x F$)**: "There exists at least one $x$ in the universe such that $F$ is true."

## Variables & Substitution

- **Variable Scope**:
    - **Bound**: Occurs within the scope of a quantifier (e.g., $\forall x ... x ...$).[^def6.32]
    - **Free**: Not bound; requires external value assignment via interpretation.[^def6.32]
    - **Closed Formula**: Contains **no** free variables.[^def6.32]
- **Substitution ($F[x/t]$)**:
    - Replaces every **free** occurrence of $x$ in $F$ with term $t$.[^def6.33]
    - **Variable Capture (Warning)**:
        - Issue: If $t$ contains free variable $y$, and substitution places $t$ inside scope of $\forall y$ in $F$, $y$ becomes unintentionally bound.
        - *Solution*: Rename bound variables in $F$ **before** substitution.
- **Rectified Form**:
    - No variable is both bound and free; all quantifiers bind distinct variables.[^def6.37]
    - **Bound Substitution**: Bound variables are dummy placeholders; can be renamed without changing semantics ($\forall x G \equiv \forall y G[x/y]$).[^lem6.9]

## Semantics

- **Interpretation (Structure $\mathcal{A}$)**:[^def6.34]
    - $\mathcal{A} = (U, \phi, \psi, \xi)$.
    - **Universe ($U$)**: Non-empty set of objects (e.g., $\mathbb{N}, \mathbb{R}$).
    - **Function mapping ($\phi$)**: $f^\mathcal{A}: U^k \to U$.
    - **Predicate mapping ($\psi$)**: $P^\mathcal{A}: U^k \to \{0, 1\}$.
    - **Variable assignment ($\xi$)**: Assigns values $u \in U$ to **free** variables.
- **Suitability**:
    - $\mathcal{A}$ is **suitable** for $F$ if it defines all symbols and free variables in $F$.[^def6.35]
- **Evaluation**:
    - **Terms**: Recursively evaluated; variables take values from $\xi$.[^def6.36]
    - **Formulas ($\mathcal{A}(F)$)**:
        - Operators: Standard propositional logic rules.
        - **Quantifiers** ("Substitution Robot"):
            - $\mathcal{A}(\forall x G) = 1$ iff $\mathcal{A}_{[x \to u]}(G) = 1$ for **all** $u \in U$.[^def6.36]
            - $\mathcal{A}(\exists x G) = 1$ iff $\mathcal{A}_{[x \to u]}(G) = 1$ for **some** $u \in U$.[^def6.36]
- **Logical Implication ($\vDash$)**:
    - $F \vDash G$: Every model of $F$ is a model of $G$.
    - **Universal Instantiation**: $\forall x F \vDash F[x/t]$ (If true for all, true for specific term).[^lem6.11]
- **Expressiveness (Infinite Universes)**:
    - Formulas can enforce infinite universes (e.g., by preventing cycles).
    - **Example**: $\underbrace{\forall x \neg P(x,x)}_{\text{Irreflexive}} \land \underbrace{\forall x P(x, f(x))}_{\text{Serial}} \land \underbrace{\forall x \forall y \forall z (P(x, y) \land P(y, z) \to P(x, z))}_{\text{Transitive}}$.
    - *Logic*: $x \xrightarrow{P} f(x) \xrightarrow{P} f(f(x)) \dots$. If finite, a cycle exists ($x \xrightarrow{P} \dots \xrightarrow{P} x$). Transitivity implies $P(x,x)$, contradicting Irreflexivity.

## Equivalences & Normal Forms

- **Quantifier Equivalences**:
    - **Negation (Pushing In)**: Flips quantifiers ($\neg \forall \equiv \exists \neg$; $\neg \exists \equiv \forall \neg$).[^lem6.7]
    - **Distribution**:
        - $\forall$ distributes over $\land$; $\exists$ distributes over $\lor$.[^lem6.7]
        - $\forall x (F \land H) \equiv (\forall x F) \land H$ (valid **only if** $x$ not free in $H$).[^lem6.7]
    - **Sub-formula Replacement**: Replacing a sub-formula with an equivalent one preserves overall equivalence.[^lem6.8]
- **Prenex Normal Form (PNF)**:
    - Structure: $Q_1 x_1 \dots Q_n x_n G$ (Prefix of quantifiers + Quantifier-free Matrix).[^def6.38]
    - **Theorem**: Every formula has an equivalent PNF.[^thm6.10]
    - **Algorithm (Bubbling Up)**:
        1. Eliminate $\to, \leftrightarrow$.
        2. Push Negations inward.
        3. **Rectify** (Rename variables to avoid capture).
        4. Pull Quantifiers to front using equivalences.
- **Application**:
    - Game Theory (Chess) as PNF: $\exists x_1 \forall x_2 \exists x_3 \dots P(\dots)$ (Existence of winning strategy).

## The Limits of Logic (Diagonalization)

- **The Diagonalization Theorem**:
    - Formula: $\neg \exists x \forall y (P(y, x) \leftrightarrow \neg P(y, y))$.[^thm6.12]
    - **Meaning**: No row $x$ exists whose entries $P(y, x)$ are exactly the negation of the diagonal $P(y, y)$ for all $y$.
- **Corollaries**:
    - **Russell's Paradox**: No set $x$ contains exactly those sets $y$ that do not contain themselves ($P(y, x) := y \in x$).[^cor6.13]
    - **Uncountability**: $\{0, 1\}^\infty$ is uncountable (Cantor's diagonal argument implicit).[^cor6.14]
    - **Halting Problem**:
        - No program $x$ exists that decides the behavior of all programs $y$ (specifically negating its own output).[^cor6.15]
        - The function $y \mapsto \neg \text{Output}(y, y)$ is **uncomputable**.[^cor6.16]

[^def6.31]: **Definition 6.31.** (Syntax of predicate logic.)
    - A *variable symbol* is of the form $x_i$ with $i \in \mathbb{N}$.
    - A *function symbol* is of the form $f_i^{(k)}$ with $i, k \in \mathbb{N}$, where $k$ denotes the number of arguments of the function. Function symbols for $k = 0$ are called *constants*.
    - A *predicate symbol* is of the form $P_i^{(k)}$ with $i, k \in \mathbb{N}$, where $k$ denotes the number of arguments of the predicate.
    - A *term* is defined inductively: A variable is a term, and if $t_1, \dots, t_k$ are terms, then $f_i^{(k)}(t_1, \dots, t_k)$ is a term. For $k = 0$ one writes no parentheses.
    - A *formula* is defined inductively:
        - For any $i$ and $k$, if $t_1, \dots, t_k$ are terms, then $P_i^{(k)}(t_1, \dots, t_k)$ is a formula, called an *atomic formula*.
        - If $F$ and $G$ are formulas, then $\neg F$, $(F \land G)$, and $(F \lor G)$ are formulas.
        - If $F$ is a formula, then, for any $i$, $\forall x_i F$ and $\exists x_i F$ are formulas.

[^def6.32]: **Definition 6.32.** Every occurrence of a variable in a formula is either *bound* or *free*. If a variable $x$ occurs in a (sub-)formula of the form $\forall x G$ or $\exists x G$, then it is bound, otherwise it is free. A formula is *closed* if it contains no free variables.
[^def6.33]: **Definition 6.33.** For a formula $F$, a variable $x$ and a term $t$, $F[x/t]$ denotes the formula obtained from $F$ by substituting every free occurrence of $x$ by $t$.
[^def6.37]: **Definition 6.37.** A formula in which no variable occurs both as a bound and as a free variable and in which all variables appearing after the quantifiers are distinct is said to be in *rectified* form.
[^lem6.9]: **Lemma 6.9.** *For a formula $G$ in which $y$ does not occur, we have*
    - $\forall x G \equiv \forall y G[x/y]$,
    - $\exists x G \equiv \exists y G[x/y]$.
[^def6.34]: **Definition 6.34.** An *interpretation* or *structure* is a tuple $\mathcal{A} = (U, \phi, \psi, \xi)$ where
    - $U$ is a non-empty *universe*,
    - $\phi$ is a function assigning to each function symbol (in a certain subset of all function symbols) a function, where for a $k$-ary function symbol $f$, $\phi(f)$ is a function $U^k \to U$.
    - $\psi$ is a function assigning to each predicate symbol (in a certain subset of all predicate symbols) a function, where for a $k$-ary predicate symbol $P$, $\psi(P)$ is a function $U^k \to \{0, 1\}$, and where
    - $\xi$ is a function assigning to each variable symbol (in a certain subset of all variable symbols) a value in $U$.
[^def6.35]: **Definition 6.35.** A interpretation (structure) $\mathcal{A}$ is *suitable* for a formula $F$ if it defines all function symbols, predicate symbols, and freely occurring variables of $F$.
[^def6.36]: **Definition 6.36.** (Semantics.) For an interpretation (structure) $\mathcal{A} = (U, \phi, \psi, \xi)$, we define the value (in $U$) of terms and the truth value of formulas under that structure.
    - The value $\mathcal{A}(t)$ of a term $t$ is defined recursively as follows:
        - If $t$ is a variable, i.e., $t = x_i$, then $\mathcal{A}(t) = \xi(x_i)$.
        - If $t$ is of the form $f(t_1, \dots, t_k)$ for terms $t_1, \dots, t_k$ and a $k$-ary function symbol $f$, then $\mathcal{A}(t) = \phi(f)(\mathcal{A}(t_1), \dots, \mathcal{A}(t_k))$.
    - The truth value of a formula $F$ is defined recursively by Definition 6.16 and
        - If $F$ is of the form $F = P(t_1, \dots, t_k)$ for terms $t_1, \dots, t_k$ and a $k$-ary predicate symbol $P$, then $\mathcal{A}(F) = \psi(P)(\mathcal{A}(t_1), \dots, \mathcal{A}(t_k))$.
        - If $F$ is of the form $\forall x G$ or $\exists x G$, then let $\mathcal{A}_{[x \to u]}$ for $u$ in $U$ be the same structure as $\mathcal{A}$ except that $\xi(x)$ is overwritten by $u$ (i.e., $\xi(x) = u$):
            $$ \mathcal{A}(\forall x G) = \begin{cases} 1 & \text{if } \mathcal{A}_{[x \to u]}(G) = 1 \text{ for all } u \text{ in } U \\ 0 & \text{else} \end{cases} $$
            $$ \mathcal{A}(\exists x G) = \begin{cases} 1 & \text{if } \mathcal{A}_{[x \to u]}(G) = 1 \text{ for some } u \text{ in } U \\ 0 & \text{else.} \end{cases} $$
[^lem6.11]: **Lemma 6.11.** *For any formula $F$ and any term $t$ we have*
    $$ \forall x F \vDash F[x/t]. $$
[^lem6.7]: **Lemma 6.7.** *For any formulas $F, G$, and $H$, where $x$ does not occur free in $H$, we have*
    1. $\neg(\forall x F) \equiv \exists x \neg F$;
    2. $\neg(\exists x F) \equiv \forall x \neg F$;
    3. $(\forall x F) \land (\forall x G) \equiv \forall x (F \land G)$;
    4. $(\exists x F) \lor (\exists x G) \equiv \exists x (F \lor G)$;
    5. $\forall x \forall y F \equiv \forall y \forall x F$;
    6. $\exists x \exists y F \equiv \exists y \exists x F$;
    7. $(\forall x F) \land H \equiv \forall x (F \land H)$;
    8. $(\forall x F) \lor H \equiv \forall x (F \lor H)$;
    9. $(\exists x F) \land H \equiv \exists x (F \land H)$;
    10. $(\exists x F) \lor H \equiv \exists x (F \lor H)$.

[^lem6.8]: **Lemma 6.8.** *If one replaces a sub-formula $G$ of a formula $F$ by an equivalent (to $G$) formula $H$, then the resulting formula is equivalent to $F$.*
[^def6.38]: **Definition 6.38.** A formula of the form
    $$ Q_1 x_1 Q_2 x_2 \dots Q_n x_n G, $$
    where the $Q_i$ are arbitrary quantifiers ($\forall$ or $\exists$) and $G$ is a formula free of quantifiers, is said to be in *prenex form*.
[^thm6.10]: **Theorem 6.10.** *For every formula there is an equivalent formula in prenex form.*
[^thm6.12]: **Theorem 6.12.** $\neg \exists x \forall y (P(y, x) \leftrightarrow \neg P(y, y))$.
[^cor6.13]: **Corollary 6.13.** *There exists no set that contains all sets $S$ that do not contain themselves, i.e., $\{S \mid S \notin S\}$ is not a set.*
[^cor6.14]: **Corollary 6.14.** *The set $\{0, 1\}^\infty$ is uncountable.*
[^cor6.15]: **Corollary 6.15.** *There are uncomputable functions $\mathbb{N} \to \{0, 1\}$.*
[^cor6.16]: **Corollary 6.16.** *The function $\mathbb{N} \to \{0, 1\}$ assigning to each $y \in \mathbb{N}$ the complement of what program $y$ outputs on input $y$, is uncomputable.*
