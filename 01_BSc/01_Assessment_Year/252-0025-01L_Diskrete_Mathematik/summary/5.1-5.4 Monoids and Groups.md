## Introduction to Algebraic Structures

- An **algebra** $\langle S; \Omega \rangle$ (or **algebraic structure**) is a set $S$ (the **carrier** ) with one or more **operations** $\Omega$.[^def5.2]
- An **operation** is a function $S^n \to S$, where $n$ is the **arity**.[^def5.1]
    - **Binary** ($n=2$): e.g., addition (+), multiplication (·).
    - **Unary** ($n=1$): e.g., negation (-a).
    - **Nullary** ($n=0$): A constant, e.g., 0 or 1.
- **Possible Properties of Operations**:
    - **Associativity**: $(x * y) * z = x * (y * z)$.[^def5.4]
        - More crucial than commutativity.
        - Allows writing expressions like $a_1 * a_2 * \dots * a_n$ without parentheses.
    - **Commutativity**: $x * y = y * x$. A group with this property is **abelian**.[^def5.8]

## Monoids: The First Step

- A **monoid** is an algebra $\langle M; *, e \rangle$ where $*$ is **associative** and $e$ is the **neutral element**.[^def5.5]
- **Neutral Element** ($e$):
    - An element that leaves others unchanged: $e * a = a * e = a$.[^def5.3]
    - If a left-neutral element ($e*a=a$) and a right-neutral element ($a*e'=a$) exist, they must be identical ($e=e'$).[^lem5.1]
- **Inverse Element**:
    - In a structure with a neutral element $e$, $b$ is a **left-inverse** of $a$ if $b * a = e$; $c$ is a **right-inverse** if $a * c = e$.[^def5.6]
    - In a **monoid**, if an element has both a left- and a right-inverse, they are unique and identical (proof requires associativity).[^lem5.2]
- **Examples**:
    - Finite bitstrings $\langle \{0,1\}^*; |, \epsilon \rangle$ with concatenation. Not a group, as only $\epsilon$ has an inverse.
    - Functions $A \to A$ with composition $\langle A^A; \circ, \text{id} \rangle$.

## Groups: The Core Structure

- A **group** is a **monoid** where **every element has an inverse**.[^def5.7]
- **Axioms**: A structure $\langle G; *, \hat{}, e \rangle$ is a group if it satisfies:
    - **G1**: $*$ is **associative**.
    - **G2**: $e$ is the **neutral element**.
    - **G3**: Every element $a$ has an **inverse** $\hat{a}$ such that $a * \hat{a} = \hat{a} * a = e$.
- **Fundamental Rules**: For any group $G$:[^lem5.3]
    - **Inverse of Inverse**: $\hat{\hat{a}} = a$.
    - **Inverse of a Product**: $\widehat{a*b} = \hat{b}*\hat{a}$ (order reverses).
    - **Cancellation Laws**: $a*b = a*c \implies b=c$ (left cancellation); $b*a = c*a \implies b=c$ (right cancellation).
    - Implies no element repeats in any row/column of the operation table.

## Group Notations

- **Multiplicative Notation (Default)**
    - **Operation**: $\cdot$ or omitted ($ab$ for $a*b$).
    - **Neutral Element**: $e$ or $1$.
    - **Inverse of $a$**: $a^{-1}$ or $\hat{a}$.
    - **Powers**: For $n \in \mathbb{Z}$, $a^n$ is defined recursively:
        - $a^0 \stackrel{\text{def}}{=} e$
        - $a^n \stackrel{\text{def}}{=} a \cdot a^{n-1}$ for $n \ge 1$
        - $a^n \stackrel{\text{def}}{=} (a^{-1})^{|n|}$ for $n \le -1$
- **Additive Notation**
    - **Usage**: Typically for abelian groups (e.g., $\langle Z_m; \oplus \rangle$).
    - **Operation**: $+$.
    - **Neutral Element**: $0$.
    - **Inverse of $a$**: $-a$.
    - **Multiples of elements**: Power notation $a^n$ translates to multiples.
        - $a^n$ becomes $n \cdot a$ (n-fold addition of $a$).
        - $a^{-n}$ becomes $(-n) \cdot a$.

## Special Groups

- **Subgroups**:
    - A subset $H \subseteq G$ that is a group under $G$'s operation.[^def5.11]
    - Requires $H$ to be closed under the operation, contain $e$, and contain the inverse for each of its elements.
    - Example: In $\langle Z_8; \oplus \rangle$, the set $\{0, 4\}$ is a subgroup.
- **Cyclic Groups**:
    - A group $G$ is **cyclic** if it can be generated by a single element $g$ (the **generator**), i.e., $G = \langle g \rangle = \{g^n \mid n \in \mathbb{Z}\}$.[^def5.14] [^def5.15]
    - A finite cyclic group of order $n$ is isomorphic to $\langle Z_n; \oplus \rangle$.[^thm5.7]
    - A group of prime order $p$ is always cyclic, and every non-neutral element is a generator.[^cor5.11]
- **Direct Products ($G_1 \times G_2$)**:
    - Constructs larger groups from smaller ones. **Very exam-relevant**.
    - Carrier: Cartesian product $G_1 \times G_2$ (set of ordered pairs $(g_1, g_2)$).
    - Operation: Performed **component-wise**: $(a_1, a_2) * (b_1, b_2) = (a_1 *_{G_1} b_1, a_2 *_{G_2} b_2)$.[^def5.9]
    - The result is guaranteed to be a group.[^lem5.4]
    - Example: The Klein four-group is isomorphic to $Z_2 \times Z_2$.

## Important Group Families

- **Additive Groups ($\langle Z_m; \oplus \rangle$)**:
    - Carrier: $\{0, 1, \dots, m-1\}$.
    - Operation: Addition modulo $m$.
    - Neutral element: $0$.
    - Inverse of $a$: $-a \pmod m$.
- **Multiplicative Groups ($\langle Z_m^*; \odot \rangle$)**:
    - Carrier: Numbers $a \in \{1, \dots, m-1\}$ **coprime** to $m$ ($gcd(a,m)=1$).[^def5.16]
    - Operation: Multiplication modulo $m$.
    - Neutral element: $1$.
    - Inverse of $a$: Modular multiplicative inverse $a^{-1}$.
    - Order is given by **Euler's totient function** $\phi(m)$.[^def5.17] [^thm5.13]
        - Calculated via prime factorization: if $m = \prod p_i^{e_i}$, then $\phi(m) = \prod (p_i - 1)p_i^{e_i-1}$.[^lem5.12]
- **Symmetric Group ($\langle S_n; \circ \rangle$)**:
    - Carrier: All **permutations** (bijective functions) of $n$ elements.
    - Operation: **Function composition**.
    - Neutral element: The identity function.
    - For $n \ge 3$, $S_n$ is **non-commutative**. ($S_3$ is the first example, with $3! = 6$ elements).

## Homomorphisms & Isomorphisms

- A **homomorphism** is a function $\psi: G_1 \to G_2$ that preserves group structure: $\psi(a *_{1} b) = \psi(a) *_{2} \psi(b)$.[^def5.10]
- An **isomorphism** is a **bijective** homomorphism.
    - If one exists, groups $G_1$ and $G_2$ are **isomorphic** ($G_1 \cong G_2$), meaning they are structurally identical.
- Properties: A homomorphism maps the neutral element to the neutral element and inverses to inverses.[^lem5.5]
- **Examples**:
    - $Z_6 \cong Z_2 \times Z_3$. The isomorphism is given by the **Chinese Remainder Theorem**. Holds generally for $Z_{mn} \cong Z_m \times Z_n$ if $m, n$ are coprime.
    - $Z_4 \not\cong Z_2 \times Z_2$. Structures differ: in $Z_2 \times Z_2$ every element is its own inverse, but in $Z_4$, $ord(1)=4$.

## Order and Lagrange's Theorem

- **Order of a group** $|G|$: The number of elements in the group.[^def5.13]
- **Order of an element** $ord(a)$: Smallest integer $m \ge 1$ such that $a^m = e$.[^def5.12]
    - Note: In additive groups like $Z_m$, $a^m$ corresponds to $m \cdot a$.
    - In a **finite group**, every element has a finite order.[^lem5.6]
- **Lagrange's Theorem**: Cornerstone of finite group theory.
    - If $H$ is a subgroup of a finite group $G$, then $|H|$ divides $|G|$.[^thm5.8]
    - **Corollary**: The order of any element divides the order of the group ($ord(a)$ divides $|G|$).[^cor5.9]
    - **Corollary**: For any element $a$ in a finite group $G$, $a^{|G|} = e$.[^cor5.10]

## RSA Public-Key Encryption

### Mathematical Foundation

- **Context**: Based on modular exponentiation in $\mathbb{Z}_n^*$.
- **Euler-Fermat**: For any $m \ge 2$, units satisfy $a^{\phi(m)} \equiv_m 1$.[^cor5.14]
- **Cyclic Structure**: $\mathbb{Z}_m^*$ is cyclic only for specific $m$ (e.g., $2, 4, p^e, 2p^e$).[^thm5.15]
- **$e$-th Roots**: In a finite group $G$, the map $x \mapsto x^e$ is bijective **if and only if** $\gcd(e, |G|) = 1$.[^thm5.16]
    - The inverse is $y \mapsto y^d$ where $ed \equiv 1 \pmod{|G|}$.
    - RSA relies on the fact that finding $d$ without knowing $|G|$ (which requires factoring the modulus) is hard.

### The Protocol

- **Key Generation (Alice)**:
    1. Pick large primes $p, q$.
    2. $n = p \cdot q$ (Modulus).
    3. $\phi(n) = (p-1)(q-1)$ (Group order).
    4. Choose public exponent $e$ with $\gcd(e, \phi(n)) = 1$.
    5. Compute private exponent $d = e^{-1} \pmod{\phi(n)}$.
    - **Public Key**: $(n, e)$. **Private Key**: $d$.
- **Encryption (Bob)**: $c \equiv m^e \pmod n$.
- **Decryption (Alice)**: $m \equiv c^d \pmod n$.
- **Digital Signatures**:
    - Sign: $s \equiv h(m)^d \pmod n$.
    - Verify: $h(m) \equiv s^e \pmod n$.

    (iv) Right cancellation law: $b * a = c * a \implies b = c$.
