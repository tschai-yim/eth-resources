- **Motivation:** An **expressive** extension of propositional logic; formalizes complex statements about objects, their properties, and relationships.
- **Expressiveness & Limits:**
    - **Can express:** Complex properties like primality.
        - `Prime(x)` $\overset{\text{def}}{=}$ $x > 1 \land \forall y \forall z ((y \cdot z = x) \rightarrow (y=1 \lor z=1))$
    - **Cannot express:** Concepts requiring infinite chains or recursion, like defining an **ancestor**, which would need an infinite disjunction: `Parent(x,y) ∨ Grandparent(x,y) ∨ ...`

## Building Blocks (Syntax)

- **Universe ($U$):** **Non-empty set** of objects to reason about (e.g., $\mathbb{N}$, $\mathbb{R}$).
- **Constants:** Specific, fixed elements from $U$ (e.g., $0, 1, \pi$).
- **Predicates:** Functions mapping elements from $U$ to a truth value, $\{0, 1\}$.
    - Example: `less(x, y)` returns $1$ if $x < y$.

> **Definition 2.10.** A $k$-ary predicate $P$ on $U$ is a function $U^k \to \{0,1\}$.

- **Functions:** Map elements from $U$ to another element in $U$.
    - Example: `add(x, y)` on $\mathbb{N}$ returns $x+y$.
- **Variables:** Placeholders for elements from $U$ (e.g., $x, y, z$).
- **Logical Operators:** From propositional logic: $\neg, \land, \lor, \rightarrow, \leftrightarrow$.
- **Quantifiers:** Tools for expressing scope.

> **Definition 2.11.** For a universe $U$ and predicate $P(x)$ we define the following logical statements:
> - $∀x P(x)$ stands for: $P(x)$ is true for all $x$ in $U$.
> - $∃x P(x)$ stands for: $P(x)$ is true for some $x$ in $U$, i.e., there exists an $x$ in $U$ for which $P(x)$ is true.
> 
> More generally, for a formula $F$ with a variable $x$, which for each value $x$ in $U$ is either true or false, the formula $∀x F$ is true if and only if $F$ is true for all $x$ in $U$, and the formula $∃x F$ is true if and only if $F$ is true for some $x$ in $U$.

## Meaning (Semantics)

- **Interpretation:** A formula is a syntactic object; it gets a **truth value** (becomes true or false) only under a specific **interpretation**, which fixes:
    1. The **universe** $U$.
    2. The meaning of all **predicate** and **function** symbols.
- **Formulas vs. Mathematical Statements:**
    - **Formula:** A syntactically correct expression (e.g., $∀x (P(x) \rightarrow Q(x))$); not a statement itself as its truth depends on the interpretation.
    - **Statement:** A formula with a **fixed interpretation**, making it unambiguously true or false (e.g., if $U=\mathbb{N}$, $P(x)$ means "$x$ is divisible by 4", and $Q(x)$ means "$x$ is even", the formula above is a true statement).

## Quantifiers in Depth

- **Universal Quantifier ($∀$):** "For all".
- **Existential Quantifier ($∃$):** "There exists".
- **Nested Quantifiers & Order:** Order of **different** quantifiers matters crucially.
    - $∀x ∃y (y > x)$ is **true** over $\mathbb{N}$ ("for every number, there's a larger one").
    - $∃y ∀x (y > x)$ is **false** over $\mathbb{N}$ ("there is a number larger than all numbers").
    - Order of **identical** quantifiers does not matter (e.g., $∀x ∀y \equiv ∀y ∀x$).
- **Variable Scope:** A quantifier binds a variable within its scope; variables with the same name in different scopes are independent.
    - Example: In $∃x (x \le 2) \land ∃x (x \ge 3)$, the left $x$ is independent of the right $x$.
- **Unique Existence ($∃!$):** **No built-in quantifier** for "exactly one"; constructed using equality (requires a $=$ predicate):
    - $∃x (P(x) \land ∀y(P(y) \rightarrow y=x))$

## Properties & Rules

- **Satisfiability & Tautologies:**
    - **Satisfiable** formula: True for at least one interpretation.
    - **Tautology** (or **valid**) formula: True for **all** interpretations.
- **Equivalence ($≡$) & Consequence ($\models$):** Statements **about** formulas.
    - **Logical Equivalence ($F \equiv G$):** $F$ and $G$ have the same truth value for all interpretations.
    - **Logical Consequence ($F \models G$):** In any interpretation where $F$ is true, $G$ must also be true.
- **Rules for Negating Quantifiers:**
    - $¬∀x P(x) \equiv ∃x ¬P(x)$
    - $¬∃x P(x) \equiv ∀x ¬P(x)$
- **Rules for Distributing Quantifiers:**
    - $∀x P(x) \land ∀x Q(x) \equiv ∀x (P(x) \land Q(x))$
    - $∃x (P(x) \lor Q(x)) \equiv ∃x P(x) \lor ∃x Q(x)$
    - **Warning:** Other combinations are generally not valid.
        - $∃x P(x) \land ∃x Q(x) \not\models ∃x (P(x) \land Q(x))$
        - Example: $∃x (\text{x is even}) \land ∃x (\text{x is odd})$ is true, but $∃x (\text{x is even} \land \text{x is odd})$ is false.
