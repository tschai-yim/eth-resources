## Relations: Core Concepts

- **Relation** $\rho$ (from $A$ to $B$): A subset of the Cartesian product $A \times B$.[^def3.9]
    - **Relation on A**: A relation from $A$ to $A$.
    - **Notation**: $a \rho b$ instead of $(a, b) \in \rho$.
    - **Example**: `takes(student, course)`.
- **Identity relation** ($id_A$): All pairs $(a,a)$ for $a \in A$.[^def3.10]

## Operations on Relations

- **Inverse Relation** ($\hat{\rho}$ or $\rho^{-1}$):
    - Relation from $B$ to $A$ containing all pairs $(b,a)$ for which $(a,b) \in \rho$.[^def3.11]
    - **Intuition**: All arrows in a graphical representation are reversed.
    - **Example**: Inverse of `child` is `parent`; inverse of $\le$ is $\ge$.
- **Composition of Relations** ($\rho \circ \sigma$ or $\rho\sigma$):
    - Relation from $A$ to $C$ (for $\rho: A \to B$ and $\sigma: B \to C$).[^def3.12]
    - Contains $(a,c)$ if there exists an intermediate $b \in B$ such that $a \rho b$ and $b \sigma c$.
    - **Example**: `takes` $\circ$ `teaches`$\hat{}$ connects students to their lecturers.
    - **Associativity**: Composition is associative: $(\rho \circ \sigma) \circ \phi = \rho \circ (\sigma \circ \phi)$.[^lem3.7]
    - **Inverse of Composition**: The inverse is the composition of the inverses in **reverse order**: $\widehat{(\rho \circ \sigma)} = \hat{\sigma} \circ \hat{\rho}$.[^lem3.8]
- **Powers of a Relation** ($\rho^n$): The $n$-fold composition of $\rho$ with itself.
    - **Example**: If `parent` is a relation, `parent`$^2$ is the `grandparent` relation.
- **Transitive Closure** ($\rho^*$):
    - The union of all positive integer powers of $\rho$: $\rho^* = \bigcup_{n \in \mathbb{N}\setminus\{0\}} \rho^n = \rho \cup \rho^2 \cup \rho^3 \cup \dots$.[^def3.18]
    - Represents reachability: $a \rho^* b$ means a path of any finite length exists from $a$ to $b$.
    - **Example**: The transitive closure of the `parent` relation is the `ancestor` relation.

## Properties of Relations on a Set

| Property | Formal Definition | Set-Theoretic Characterization |
| :--- | :--- | :--- |
| **Reflexive** | $\forall a: a \rho a$[^def3.13] | $id \subseteq \rho$ |
| **Irreflexive** | $\forall a: \neg(a \rho a)$[^def3.14] | $id \cap \rho = \emptyset$ |
| **Symmetric** | $\forall a, b: a \rho b \iff b \rho a$[^def3.15] | $\rho = \hat{\rho}$ |
| **Antisymmetric**| $\forall a, b: (a \rho b \land b \rho a) \Rightarrow a=b$[^def3.16] | $\rho \cap \hat{\rho} \subseteq id$ |
| **Transitive** | $\forall a, b, c: (a \rho b \land b \rho c) \Rightarrow a \rho c$[^def3.17]| $\rho^2 \subseteq \rho$[^lem3.9] |

- **Crucial Distinctions**:
    - **Irreflexive vs. Not Reflexive**: A relation is *not reflexive* if at least one element is not related to itself. It is *irreflexive* only if **no** element is related to itself.
    - **Antisymmetric is not the negation of symmetric**.
- **Transitivity Characterization**: A relation $\rho$ is transitive $\iff \rho \circ \rho \subseteq \rho$.[^lem3.9]
    - **Proof Idea ($\Rightarrow$)**: If $(a,c) \in \rho^2$, then $\exists b: (a,b) \in \rho \land (b,c) \in \rho$. By transitivity, $(a,c) \in \rho$.
    - **Proof Idea ($\Leftarrow$)**: If $(a,b) \in \rho \land (b,c) \in \rho$, then $(a,c) \in \rho^2$. Since $\rho^2 \subseteq \rho$, it follows that $(a,c) \in \rho$.

[^def3.9]: **Definition 3.9.** A (binary) relation $\rho$ from a set $A$ to a set $B$ (also called an $(A, B)$-relation) is a subset of $A \times B$. If $A = B$, then $\rho$ is called a relation on $A$.
[^def3.10]: **Definition 3.10.** For any set $A$, the identity relation on $A$, denoted $id_A$ (or simply id), is the relation $id_A = \{(a, a)| a \in A\}$.
[^def3.11]: **Definition 3.11.** The inverse of a relation $\rho$ from $A$ to $B$ is the relation $\hat{\rho}$ from $B$ to $A$ defined by $\hat{\rho} \stackrel{\text{def}}{=} \{(b, a) \mid (a, b) \in \rho\}$.
[^def3.12]: **Definition 3.12.** Let $\rho$ be a relation from $A$ to $B$ and let $\sigma$ be a relation from $B$ to $C$. Then the composition of $\rho$ and $\sigma$, denoted $\rho \circ \sigma$ (or also $\rho\sigma$), is the relation from $A$ to $C$ defined by $\rho \circ \sigma \stackrel{\text{def}}{=} \{(a, c) \mid \exists b ((a, b) \in \rho \land (b, c) \in \sigma)\}$. The n-fold composition of a relation $\rho$ on a set $A$ with itself is denoted $\rho^n$.
[^lem3.7]: **Lemma 3.7.** The composition of relations is associative, i.e., we have $\rho \circ (\sigma \circ \phi) = (\rho \circ \sigma) \circ \phi$.
[^lem3.8]: **Lemma 3.8.** Let $\rho$ be a relation from $A$ to $B$ and let $\sigma$ be a relation from $B$ to $C$. Then the inverse $\widehat{\rho\sigma}$ of $\rho\sigma$ is the relation $\hat{\sigma}\hat{\rho}$.
[^def3.18]: **Definition 3.18.** The transitive closure of a relation $\rho$ on a set $A$, denoted $\rho^*$, is $\rho^* = \bigcup_{n \in \mathbb{N}\setminus\{0\}} \rho^n$.
[^def3.13]: **Definition 3.13.** A relation $\rho$ on a set $A$ is called reflexive if $a \rho a$ is true for all $a \in A$, i.e., if $id \subseteq \rho$.
[^def3.14]: **Definition 3.14.** A relation $\rho$ on a set $A$ is called irreflexive if $a \not\rho a$ for all $a \in A$, i.e., if $\rho \cap id = \emptyset$.
[^def3.15]: **Definition 3.15.** A relation $\rho$ on a set $A$ is called symmetric if $a \rho b \iff b \rho a$ is true for all $a, b \in A$, i.e., if $\rho = \hat{\rho}$.
[^def3.16]: **Definition 3.16.** A relation $\rho$ on a set $A$ is called antisymmetric if $a \rho b \land b \rho a \implies a=b$ is true for all $a, b \in A$, i.e., if $\rho \cap \hat{\rho} \subseteq id$.
[^def3.17]: **Definition 3.17.** A relation $\rho$ on a set $A$ is called transitive if $a \rho b \land b \rho c \implies a \rho c$ is true for all $a, b, c \in A$.
[^lem3.9]: **Lemma 3.9.** A relation $\rho$ is transitive if and only if $\rho^2 \subseteq \rho$.
