- **Comparing Set Sizes**:
    - **Equinumerous ($A \sim B$)**: Sets have the "same size". Defined by a **bijection** between them. Forms an equivalence relation.[^def3.42][^lem3.15]
    - **Domination ($A \preceq B$)**: Set $A$ is "no larger than" set $B$. Defined by an **injection** from $A$ to $B$. Reflexive and transitive.[^def3.42][^lem3.15]
- **Countability**:
    - **Countable set**: A set $A$ where $A \preceq \mathbb{N}$.[^def3.42]
    - **Theorem 3.17**: A set is countable iff it is **finite** or equinumerous to $\mathbb{N}$ ($A \sim \mathbb{N}$).[^thm3.17]
        - Key insight: **No level of infinity** exists between finite sets and $\mathbb{N}$.
- **Important Countable Sets**:
    - Integers $\mathbb{Z}$.[^ex3.56]
    - Rational numbers $\mathbb{Q}$.[^cor3.21]
    - Cartesian products of countable sets, e.g., $\mathbb{N} \times \mathbb{N}$.[^thm3.19][^cor3.20]
    - Sets of all **finite** sequences over countable sets, e.g., $\{0,1\}^*$ (finite bitstrings).[^thm3.18][^thm3.22]
- **Uncountability**:
    - **Uncountable set**: A set that is not countable.[^def3.42]
    - The set of **infinite** binary sequences, $\{0,1\}^\infty$, is uncountable.[^thm3.23]
    - **Proof: Cantor's Diagonalization Argument**:
        1. Assume all infinite binary sequences can be listed.
        2. Construct a new sequence by flipping the bits along the diagonal of this list.
        3. This new sequence cannot be in the list, a contradiction.
    - The powerset $P(\mathbb{N})$ is also uncountable ($P(\mathbb{N}) \sim \{0,1\}^\infty$).
- **Fundamental Consequences**:
    - **Bernstein-Schröder Theorem**: If two sets dominate each other, they are equinumerous ($A \preceq B \land B \preceq A \implies A \sim B$).[^thm3.16]
    - **Existence of Uncomputable Functions**:
        - Computer programs are **countable** (can be encoded as finite strings).
        - Functions $f: \mathbb{N} \to \{0,1\}$ are **uncountable** (equinumerous to $\{0,1\}^\infty$).[^def3.43]
        - Consequence: More functions than programs exist, so some functions must be **uncomputable**.[^def3.44][^cor3.24]

[^def3.42]: **Definition 3.42.**
    (i) Two sets $A$ and $B$ **equinumerous**, denoted $A \sim B$, if there exists a bijection $A \to B$.
    (ii) The set $B$ **dominates** the set $A$, denoted $A \preceq B$, if $A \sim C$ for some subset $C \subseteq B$ or, equivalently, if there exists an injective function $A \to B$.
    (iii) A set $A$ is called **countable** if $A \preceq \mathbb{N}$, and **uncountable** otherwise.
[^lem3.15]: **Lemma 3.15.**
    (i) The relation $\sim$ is an equivalence relation.
    (ii) The relation $\preceq$ is transitive: $A \preceq B \land B \preceq C \implies A \preceq C$.
    (iii) $A \subseteq B \implies A \preceq B$.
[^thm3.17]: **Theorem 3.17.** A set $A$ is countable if and only if it is finite or if $A \sim \mathbb{N}$.
[^ex3.56]: **Example 3.56.** The set Z = {..., -2, -1, 0, 1, 2, . . .} of integers is countable, and Z ~ N. A bijection $f : N \to Z$ is given by $f(n) = (-1)^n \lceil n/2 \rceil$.
[^cor3.21]: **Corollary 3.21.** The rational numbers $\mathbb{Q}$ are countable.
[^thm3.19]: **Theorem 3.19.** The set $\mathbb{N} \times \mathbb{N}$ of ordered pairs of natural numbers is countable.
[^cor3.20]: **Corollary 3.20.** The Cartesian product $A \times B$ of two countable sets $A$ and $B$ is countable, i.e., $A \preceq \mathbb{N} \land B \preceq \mathbb{N} \implies A \times B \preceq \mathbb{N}$.
[^thm3.18]: **Theorem 3.18.** The set $\{0,1\}^*$ of finite binary sequences is countable.
[^thm3.22]: **Theorem 3.22.** Let $A$ and $A_i$ for $i \in \mathbb{N}$ be countable sets.
    (i) For any $n \in \mathbb{N}$, the set $A^n$ of $n$-tuples over $A$ is countable.
    (ii) The union $\bigcup_{i \in \mathbb{N}} A_i$ of a countable list $A_0, A_1, A_2, \dots$ of countable sets is countable.
    (iii) The set $A^*$ of finite sequences of elements from $A$ is countable.
[^thm3.23]: **Theorem 3.23.** The set $\{0,1\}^\infty$ is uncountable.
[^thm3.16]: **Theorem 3.16 (Bernstein-Schröder).** $A \preceq B \land B \preceq A \implies A \sim B$.
[^def3.43]: **Definition 3.43.** Let $\{0,1\}^\infty$ denote the set of semi-infinite binary sequences or, equivalently, the set of functions $\mathbb{N} \to \{0,1\}$.
[^def3.44]: **Definition 3.44.** A function $f: \mathbb{N} \to \{0,1\}$ is called **computable** if there is a program that, for every $n \in \mathbb{N}$, when given $n$ as input, outputs $f(n)$.
[^cor3.24]: **Corollary 3.24.** There are uncomputable functions $\mathbb{N} \to \{0,1\}$.
