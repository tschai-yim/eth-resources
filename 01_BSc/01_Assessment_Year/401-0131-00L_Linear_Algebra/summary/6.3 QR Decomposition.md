Orthonormal bases simplify projections ($A^\top A = I$) and numerical stability.

## Definitions

- **Orthonormal Vectors:** Set $q_1, \dots, q_n$ where $q_i^\top q_j = \delta_{ij}$ (unit length, pairwise orthogonal) .[^def6.3.1]
    - Example: Canonical basis $e_i$ .[^ex6.3.2]
- **Orthogonal Matrix ($Q$):** Square matrix with orthonormal columns.
    - Properties: $Q^\top Q = I \implies Q^{-1} = Q^\top$ .[^def6.3.3]
    - Preserves geometry: $\|Qx\| = \|x\|$ and $(Qx)^\top(Qy) = x^\top y$ (preserves angles and lengths) .[^prop6.3.6]
    - Examples: Rotation matrices ,[^ex6.3.4] Permutation matrices .[^ex6.3.5]

## Gram-Schmidt & QR

- **Gram-Schmidt Process:** Converts linearly independent vectors $a_1, \dots, a_n$ into orthonormal vectors $q_1, \dots, q_n$ spanning the same subspaces $S_k = \operatorname{span}(a_1 \dots a_k)$.
    1. Orthogonalize: $q'_k = a_k - \sum_{i=1}^{k-1} (a_k^\top q_i)q_i$ (remove projections onto previous $q$'s) .[^alg6.3.8][^thm6.3.9]
    2. Normalize: $q_k = \frac{q'_k}{\|q'_k\|}$ .[^alg6.3.8]
- **QR Decomposition:** Any matrix $A$ with independent columns can be factored as $A = QR$ .[^def6.3.10]
    - $Q$: Orthonormal columns (from Gram-Schmidt).
    - $R$: Upper triangular and invertible ($R = Q^\top A$) .[^lem6.3.11]
- **Advantages:**
    - **Projections:** Projecting onto $C(A)$ simplifies to $P = QQ^\top$ .[^prop6.3.7]
        - Standard formula: $P = A(A^\top A)^{-1}A^\top$.
        - With orthonormal columns ($A=Q$): $Q^\top Q = I$, eliminating the inverse $(Q^\top Q)^{-1}$.
        - Result: No matrix inversion required.
    - **Least Squares:** Solving $A^\top A \hat{x} = A^\top b$ simplifies to solving $R\hat{x} = Q^\top b$ via back-substitution (numerically stable) .[^fact6.3.12]

[^def6.3.1]: **Definition 6.3.1 (Orthonormal vectors).** Vectors $q_1, \dots, q_n \in \mathbb{R}^m$ are orthonormal if they are orthogonal and have norm 1. In other words, for all $i, j \in \{1, \dots, n\}$ $$q_i^\top q_j = \delta_{ij},$$ where $\delta_{ij}$ is the Kronecker delta $$(8) \quad \delta_{ij} = \begin{cases} 0 & \text{if } i \neq j \\ 1 & \text{if } i = j. \end{cases}$$
[^ex6.3.2]: **Example 6.3.2.** A classical example of an orthonormal set of vectors is the canonical basis, $e^1, \dots, e^n \in \mathbb{R}^n$ where $e^i$ is the vector with a 1 in the $i$-th entry and 0 in all other entries, i.e., $(e^i)_j = \delta_{ij}$.
[^def6.3.3]: **Definition 6.3.3 (Orthogonal Matrix).** A square matrix $Q \in \mathbb{R}^{n \times n}$ is an orthogonal matrix when $Q^\top Q = I$. In this case, $QQ^\top = I$, $Q^{-1} = Q^\top$, and the columns of $Q$ form an orthonormal basis for $\mathbb{R}^n$.
[^prop6.3.6]: **Proposition 6.3.6.** Orthogonal matrices preserve norm and inner product of vectors. In other words, if $Q \in \mathbb{R}^{n \times n}$ is orthogonal then, for all $x, y \in \mathbb{R}^n$ $$\|Qx\| = \|x\| \text{ and } (Qx)^\top (Qy) = x^\top y$$
[^ex6.3.4]: **Example 6.3.4.** The $2 \times 2$ matrix $Q$ that corresponds to rotating, counterclockwise, the plane by $\theta$, $$R_\theta = \begin{bmatrix} \cos \theta & -\sin \theta \\ \sin \theta & \cos \theta \end{bmatrix}$$ is an orthogonal matrix. [...]
[^ex6.3.5]: **Example 6.3.5.** Permutation matrices are another example of orthogonal matrices. [...]
[^alg6.3.8]: **Algorithm 6.3.8. Gram-Schmidt Process** Given $n$ linearly independent vectors $a_1, \dots, a_n$ that span a subspace $S$, the Gram-Schmidt process constructs $q_1, \dots, q_n$ in the following way:
    - $q_1 = \frac{a_1}{\|a_1\|}$.
    - For $k = 2, \dots, n$ set
      $q'_k = a_k - \sum_{i=1}^{k-1} (a_k^\top q_i)q_i$
      $q_k = \frac{q'_k}{\|q'_k\|}$.
[^thm6.3.9]: **Theorem 6.3.9 (Correctness of Gram-Schmidt).** Given $n$ linearly independent vectors $a_1, \dots, a_n$, the Gram-Schmidt process returns an orthonormal basis for the span of $a_1, \dots, a_n$.
[^def6.3.10]: **Definition 6.3.10 (QR decomposition).** Let $A$ be an $m \times n$ matrix with linearly independent columns. The QR decomposition is given by $$A = QR,$$ where $Q$ is an $m \times n$ matrix with orthonormal columns (they are the output of Gram Schmidt, Algorithm 6.3.8, on the columns of $A$) and $R$ is an upper triangular matrix given by $R = Q^\top A$.
[^lem6.3.11]: **Lemma 6.3.11.** The matrix $R$ defined in Definition 6.3.10 is upper triangular and invertible. Moreover, $QQ^\top A = A$ and hence, $A = QR$ is well defined.
[^prop6.3.7]: **Proposition 6.3.7.** Let $S$ be a subspace of $\mathbb{R}^m$ and $q_1, \dots, q_n$ be an orthonormal basis for $S$. Let $Q$ be the $m \times n$ matrix whose columns are the $q_i$'s; $Q = \begin{bmatrix} q_1 & \cdots & q_n \end{bmatrix}$. Then the Projection Matrix that projects to $S$ is given by $QQ^\top$ and the Least Squares solution to $Qx = b$ is given by $\hat{x} = Q^\top b$.
[^fact6.3.12]: **Fact 6.3.12.** The QR decomposition greatly simplifies calculations involving Projections and Least Squares.
    - Since $C(A) = C(Q)$ then projections on $C(A)$ can be done with $Q$ which means they are given by $\operatorname{proj}_{C(A)}(b) = QQ^\top b$.
    - The least squares solution to $Ax = b$ denoted by $\hat{x}$ is defined as a solution of the normal equations (recall (4)) $$A^\top A \hat{x} = A^\top b.$$ Furthermore, $A^\top A = (QR)^\top (QR) = R^\top Q^\top QR = R^\top R$, and so we can write $$(9) \quad R^\top R \hat{x} = R^\top Q^\top b.$$ Since $R^\top$ is invertible we can simplify (9) to $$(10) \quad R \hat{x} = Q^\top b,$$ which can be efficiently solved by back-substitution since $R$ is a triangular matrix.
