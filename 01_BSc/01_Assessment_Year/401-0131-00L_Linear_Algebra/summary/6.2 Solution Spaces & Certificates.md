## Geometry of Solutions

- **Injectivity on Row Space:** $A$ acts injectively on $C(A^\top)$; $Ax = Ay \iff x = y$ for $x,y \in C(A^\top)$ .[^lem6.2.1]
- **Unique Row-Space Solution:** If system $Ax=b$ is solvable $\implies$ exists **unique** solution $x_1 \in C(A^\top)$ .[^cor6.2.3]
- **General Solution Structure:** Set of solutions forms affine space $x_1 + N(A)$ .[^thm6.2.2]
    - $x_1 \in C(A^\top)$: Solution with **shortest length** (closest to origin).

## Certificates of Unsolvability

Prove $Ax=b$ has **no** solution:

- **Theorem of the Alternative (Fredholm):** Exactly one set non-empty :[^thm6.2.4]
    1. $P = \{x \in \mathbb{R}^n \mid Ax = b\}$ (System solvable).
    2. $D = \{z \in \mathbb{R}^m \mid A^\top z = 0, b^\top z = 1\}$ (Certificate of unsolvability).
- **Geometric Intuition:** If $Ax=b$ unsolvable $\implies b \notin C(A)$; $z \in D$ proves $z \perp \text{cols}(A)$ but $z \not\perp b$ .[^ex6.2.5]

[^lem6.2.1]: **Lemma 6.2.1.** Let $A \in \mathbb{R}^{m \times n}$. Let $x, y \in C(A^\top)$. We have that $$Ax = Ay \iff x = y.$$
[^cor6.2.3]: **Corollary 6.2.3.** Suppose that $\{x \in \mathbb{R}^n \mid Ax = b\} \neq \emptyset$. Then there exists a unique vector $x_1 \in C(A^\top A)$ such that $Ax_1 = b$.
[^thm6.2.2]: **Theorem 6.2.2.** Suppose that $\{x \in \mathbb{R}^n \mid Ax = b\} \neq \emptyset$. Then $$\{x \in \mathbb{R}^n \mid Ax = b\} = x_1 + N(A) \text{ where } x_1 \in R(A) \text{ is unique such that } Ax_1 = b.$$ *Note: The script uses $R(A)$ to denote the Row Space $C(A^\top)$.*
[^thm6.2.4]: **Theorem 6.2.4.** $$\{x \in \mathbb{R}^n \mid Ax = b\} = \emptyset \iff \{z \in \mathbb{R}^m \mid A^\top z = 0, b^\top z = 1\} \neq \emptyset.$$
[^ex6.2.5]: **Example 6.2.5.** [...] The system $D = \{z \in \mathbb{R}^m \mid A^\top z = 0, b^\top z = 1\}$ referenced in Theorem 6.2.4 is [...] $P = \emptyset$ and $D \neq \emptyset$, because $z = (1, -\frac{1}{2})^\top \in D$.
