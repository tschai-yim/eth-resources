## Notation

- **Zahlenmengen**:
    - Natürliche Zahlen: $\mathbb{N} = \{1, 2, 3, \dots\}$
    - Natürliche Zahlen mit Null: $\mathbb{N}_0 = \{0, 1, 2, 3, \dots\}$
    - Zahlen 1 bis $n$: $[n] = \{1, 2, \dots, n\}$
    - Ganze Zahlen: $\mathbb{Z} = \{\dots, -2, -1, 0, 1, 2, \dots\}$
    - Reelle Zahlen (positiv / nicht-negativ): $\mathbb{R}$, $\mathbb{R}^+$, $\mathbb{R}_{\ge 0}$
- **Mengenoperationen**:
    - **Kardinalität**: $|A|$ (Anzahl Elemente einer Menge $A$)
    - **Kartesisches Produkt**: $A \times B = \{(a, b) \mid a \in A, b \in B\}$
    - **Potenzmenge**: $2^A = \{X \mid X \subseteq A\}$ (Menge aller Teilmengen von $A$)
    - **$k$-elementige Teilmengen**: $\binom{A}{k} = \{X \mid X \subseteq A, |X| = k\}$
    - **Disjunkte Vereinigung** (disjoint union): $A \uplus B$ (Vereinigung zweier Mengen ohne gemeinsame Elemente)
- **Logarithmen**:
    - $\ln$: Natürlicher Logarithmus (Basis $e = 2.71828\dots$)
    - $\log$: Zweierlogarithmus (Basis 2)
