## Motivation für Stochastik in der Informatik

- **Kryptographie (Zero-Knowledge)**: **Zufall** beweist Geheimniskenntnis ohne Offenlegung. Ohne Geheimnis sind andauernd korrekte Antworten auf Zufallsfragen extrem unwahrscheinlich.
- **Verteiltes Rechnen**: **Deterministische Algorithmen** blockieren bei Symmetrien (identische lokale Umgebungen $\implies$ identische Entscheidungen).
- **Randomisierte Algorithmen**: Zwingend notwendig zur **Symmetriebrechung** (Symmetry Breaking) (z.B. maximale stabile Menge im Netzwerk finden).

## Wahrscheinlichkeitsraum und Ereignisse

- **Wahrscheinlichkeitsraum (Probability Space)**: Ergebnismenge $\Omega$ plus zugehörige Wahrscheinlichkeiten [^def2.1].
    - Endlich oder abzählbar unendlich (z.B. Münzwurf bis zum ersten Kopf: $\Omega = \mathbb{N}$).
    - Summenbedingung: $\sum \Pr[\omega] = 1$.
- **Ereignisse (Events)**: Mathematische Teilmengen $E \subseteq \Omega$ [^def2.1].
    - Komplementärereignis $\bar{E} = \Omega \setminus E$ (Gegenereignis).
    - Grundregeln: $\Pr[\emptyset] = 0$, $\Pr[\Omega] = 1$ [^lemma2.2].
    - Monotonie: $A \subseteq B \implies \Pr[A] \le \Pr[B]$ [^lemma2.2].
- **Wahl der Modellierung**: Absolut entscheidend für korrekte Wahrscheinlichkeiten.
    - Gleiches Problem $\implies$ verschiedene Räume möglich (z.B. 2 Würfel als Summe vs. Zahlenpaar).
    - Bei Nicht-Laplace-Räumen (z.B. Summe von Würfeln) zwingend manuelle Wahrscheinlichkeitsanpassung nötig.
- **Laplace-Raum (Laplace Space)**:
    - Endlicher Wahrscheinlichkeitsraum.
    - **Alle** Elementarereignisse **gleich wahrscheinlich** (Uniforme Verteilung).
    - Formel: $\Pr[E] = |E| / |\Omega|$.
    - Beispiel: Zahlenpaare zweier Würfel $(x_1, x_2)$ bilden einen Laplace-Raum, deren Summe jedoch nicht.

## Vereinigung von Ereignissen

- **Additionssatz (Rule of Sum)**: $\Pr[\bigcup A_i] = \sum \Pr[A_i]$ [^satz2.3].
    - **Zentrale Fehlerquelle**: Setzt zwingend **paarweise disjunkte** (mutually exclusive / schnittmengenfreie) Ereignisse voraus.
- **Boolesche Ungleichung (Union Bound)**: $\Pr[\bigcup A_i] \le \sum \Pr[A_i]$ [^kor2.6].
    - Gültig für **beliebige** (auch überlappende) Ereignisse.
    - Beweis-Trick: Definition künstlich disjunkter Mengen $B_i$ (enthalten nur zuvor nicht abgedeckte Elemente) $\implies$ Additionssatz anwendbar.

## Siebformel / Inklusion-Exklusion

- **Siebformel (Inclusion-Exclusion Principle)**: Exakte Berechnung der Vereinigung nicht-disjunkter Ereignisse [^satz2.5].
    - Nützlich bei einfacherer Berechnung von Schnittmengen (Intersections) im Vergleich zur Vereinigung.
    - Systematik: Alternierende Vorzeichen (+ Einzelereignisse, - 2er-Schnitte, + 3er-Schnitte, etc.).
    - Beweis-Trick: Binomische Formel für $(x-y)^k$ mit Spezialfall $x=y=1$ (zeigt: jedes Element exakt 1 Mal gezählt).
- **Beispiel Permutationen (Kartendeck)**:
    - Szenario: Wahrscheinlichkeit $A$, dass nach Mischen von $n$ Karten **mindestens eine Karte** am ursprünglichen Platz liegt.
    - Definition: $A_i$: Karte $i$ bleibt am Platz $\implies A = \bigcup_{i=1}^n A_i$.
    - Schnittmenge: Für eine Teilmenge $S$ mit $|S|=k$ fixierten Karten gilt $\Pr[A_S] = \frac{(n-k)!}{n!}$ (Restliche Karten frei permutierbar).
    - Summanden-Berechnung: Es gibt $\binom{n}{k}$ mögliche Schnittmengen der Grösse $k$. Jede trägt $\binom{n}{k} \cdot \frac{(n-k)!}{n!} = \frac{n!}{k!(n-k)!} \cdot \frac{(n-k)!}{n!} = \frac{1}{k!}$ zur Siebformel bei.
    - Initialreihe (Inklusion-Exklusion):$$\Pr[A] = \sum_{k=1}^n (-1)^{k+1} \cdot \frac{1}{k!} = \frac{1}{1!} - \frac{1}{2!} + \frac{1}{3!} - \dots + (-1)^{n+1} \frac{1}{n!}$$
    - Grenzwert ($n \to \infty$): Da $e^x = \sum_{k=0}^\infty \frac{x^k}{k!}$, konvergiert die Reihe gegen $1 - e^{-1} = 1 - \frac{1}{e} \approx 63.2\%$.

[^def2.1]: Definition 2.1. Ein diskreter Wahrscheinlichkeitsraum ist bestimmt durch eine Ergebnismenge $\Omega = \{\omega_1, \omega_2, \dots\}$ von Elementarereignissen. Jedem Elementarereignis $\omega_i$ ist eine (Elementar-)Wahrscheinlichkeit $\Pr[\omega_i]$ zugeordnet, wobei wir fordern, dass $0 \le \Pr[\omega_i] \le 1$ und $\sum_{\omega \in \Omega} \Pr[\omega] = 1$. Eine Menge $E \subseteq \Omega$ heisst Ereignis. Die Wahrscheinlichkeit $\Pr[E]$ eines Ereignisses ist definiert durch $\Pr[E] := \sum_{\omega \in E} \Pr[\omega]$. Ist $E$ ein Ereignis, so bezeichnen wir mit $\bar{E} := \Omega \setminus E$ das Komplementärereignis zu $E$.
[^lemma2.2]: Lemma 2.2. Für Ereignisse $A, B$ gilt: 1. $\Pr[\emptyset] = 0$, $\Pr[\Omega] = 1$. 2. $0 \le \Pr[A] \le 1$. 3. $\Pr[\bar{A}] = 1 - \Pr[A]$. 4. Wenn $A \subseteq B$, so folgt $\Pr[A] \le \Pr[B]$.
[^satz2.3]: Satz 2.3 (Additionssatz). Wenn die Ereignisse $A_1, \dots, A_n$ paarweise disjunkt sind (also wenn für alle Paare $i \neq j$ gilt, dass $A_i \cap A_j = \emptyset$), so gilt $\Pr[\bigcup_{i=1}^n A_i] = \sum_{i=1}^n \Pr[A_i]$. Für eine unendliche Menge von disjunkten Ereignissen $A_1, A_2, \dots$ gilt analog $\Pr[\bigcup_{i=1}^\infty A_i] = \sum_{i=1}^\infty \Pr[A_i]$.
[^satz2.5]: Satz 2.5. (Siebformel, Prinzip der Inklusion/Exklusion) Für Ereignisse $A_1, \dots, A_n$ ($n \ge 2$) gilt: $\Pr[\bigcup_{i=1}^n A_i] = \sum_{l=1}^n (-1)^{l+1} \sum_{1 \le i_1 < \dots < i_l \le n} \Pr[A_{i_1} \cap \dots \cap A_{i_l}] = \sum_{i=1}^n \Pr[A_i] - \sum_{1 \le i_1 < i_2 \le n} \Pr[A_{i_1} \cap A_{i_2}] + \sum_{1 \le i_1 < i_2 < i_3 \le n} \Pr[A_{i_1} \cap A_{i_2} \cap A_{i_3}] - \dots + (-1)^{n+1} \cdot \Pr[A_1 \cap \dots \cap A_n]$.
